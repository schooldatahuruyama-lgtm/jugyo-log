# AI のまとめを使えるようにする手順

先生の「記録」の画面の「AI でまとめる」を使えるようにする手順です。OpenAI の API を使います。

## 知っておくこと

- 「AI でまとめる」を押すと、その授業で生徒が**文字で書いた**「分かったこと」「疑問」「メモ」と理解度が、OpenAI に送られます。
- 送らないもの: 生徒の名前・ID・クラス名・学校名の欄、手書き、写真、PDF。生徒は「2 番」のような出席番号の呼び名だけで送ります。
- **生徒が文の中に書いた名前などは、そのまま送られます。** アプリは、文の中身から名前を見分けられません。決まった形のもの（生徒の ID、メールアドレス、10 けた以上の数字）だけは、送る前に伏せます。
- 押したときだけ送ります。開いただけでは送りません。作ったまとめは保存し、次からは保存したものを出します。
- 費用は、使った分だけかかります。1 クラス分のまとめ 1 回で、小さめのモデルなら数円ほどの見こみです（40 人が 300 文字ずつ書いた場合の計算。料金は変わることがあるので、OpenAI の料金表で確かめてください）。
- **鍵（API キー）は、パスワードと同じです。** Claude Code にも、チャットにも、アプリのコードにも書かないでください。下の手順で、先生が自分で入れます。

## 手順

### 1. OpenAI の API の鍵を用意する

1. OpenAI の API の画面（platform.openai.com）で、支払いの登録をします。
2. 鍵（API キー）を作ります。作ったときにしか全部は見られないので、なくさない所にひかえます。
3. 使いすぎを防ぐために、月の上限額を決めておくと安心です（OpenAI の画面の「Limits」などで決められます）。

### 2. 保存の仕組み（GAS）に、鍵とモデルの名前を入れる

1. 本番用の保存の仕組み（`gas/Code.gs` を貼ってある Google Apps Script のプロジェクト）を開きます。
2. 左の歯車「プロジェクトの設定」を開きます。
3. 下のほうの「スクリプト プロパティ」で、「スクリプト プロパティを追加」を押し、次の 2 つを入れます。

   | プロパティ | 値 |
   |---|---|
   | `OPENAI_API_KEY` | 作った鍵 |
   | `OPENAI_MODEL` | 使うモデルの名前（下の「モデルの名前」を見てください） |

4. 「スクリプト プロパティを保存」を押します。

前からある `DATABASE_URL` は、そのままにします。

### 3. 保存の仕組みのコードを貼り直して、新しい版を公開する

今までと同じ手順です（[gas.md](gas.md)）。

1. `gas/Code.gs` の中身を全部写して、Google Apps Script の `コード.gs` に貼りかえます。
2. 「デプロイ」→「デプロイを管理」→ 鉛筆のマーク → バージョン「新バージョン」→「デプロイ」。
3. **ウェブアプリの URL が変わっていないこと**を見ます（「デプロイを管理」から新しい版にすれば、変わりません。「新しいデプロイ」を作ると URL が変わってしまい、アプリと中つぎの両方を直すことになります）。

中つぎ（Cloudflare）は、貼り直しません。

### 4. データベースの規則を新しくする（Claude Code が行います）

AI のまとめを保存する場所（先生だけが読み書きできる）を、規則に足してあります。規則が古いままだと、「AI でまとめる」のボタンが出ません。

- 規則の貼り直しと公開は、Claude Code が行います（先生の作業は要りません）。自分で行うときは、[Firebase の手順書「9. 本番の規則を貼る」](firebase.md#9-本番の規則を貼る段階-1a) のとおりに、最新の `docs/setup/rules.json` を全部貼って「公開」を押します。
- そのあと、先生としてログインし、「規則の確認」が **128 項目すべて ○** になることを見ます。

### 5. 確かめる

1. 先生としてアプリにログインし、「記録」で、生徒が文字で書いた授業を選びます。
2. 「AI でまとめる」を押します。30 秒ほどで、まとめが出ます。

うまくいかないときに出る文と、見る所:

| 出る文 | 見る所 |
|---|---|
| AI の設定がまだです。 | 手順 2 の 2 つのプロパティが入っているか。名前のつづり |
| AI の鍵が正しくないか、使えなくなっています。 | 鍵を写しまちがえていないか。OpenAI の画面で、鍵が有効か・支払いの登録があるか |
| AI が混んでいるか、使える量をこえています。 | 少し待つ。OpenAI の画面で、上限額に届いていないか |
| 保存の仕組みが古い版のようです。 | 手順 3 の貼り直しと、新しい版の公開 |
| AI のまとめを作れませんでした。 | モデルの名前が正しいか。もう一度押す |

## モデルの名前

`OPENAI_MODEL` には、OpenAI のモデルの一覧にある名前を、そのまま入れます。まとめには、小さめ（安め）のモデルで足ります。

- 2026-11-18 に料金表で確かめた例: `gpt-5.4-mini`（入力 100 万トークンあたり 0.75 ドル・出力 4.50 ドル）、`gpt-5-mini`（0.25 ドル・2.00 ドル）。
- モデルの名前と料金は変わります。入れる前に、OpenAI のモデルの一覧と料金表で確かめてください。
- モデルを変えたいときは、`OPENAI_MODEL` の値を書きかえるだけです（コードの貼り直しは要りません）。

## やめるとき

- スクリプト プロパティの `OPENAI_API_KEY` を消します。「AI でまとめる」は「AI の設定がまだです。」になり、OpenAI へは何も送られなくなります。
- OpenAI の画面で、鍵を取り消します。
- 保存してあるまとめは、そのまま読めます。
