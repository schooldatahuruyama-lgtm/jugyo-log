# 確認用の GAS の準備の手順書（段階 0）

授業ログは、写真などのファイルを先生の Google ドライブに保存します。保存と取り出しは、先生が公開する小さなプログラム（Google Apps Script。以下 GAS）が行います。このページは、段階 0 の確認のために、その GAS を公開する手順です。順番にやれば大丈夫です。わからなくなったら、そこで止めて Claude Code に画面の様子を伝えてください。

**この確認でいちばん知りたいこと:** 学校の Google アカウントで、GAS を「全員」が使える設定で公開できるかどうかです。手順 4 で「全員」を選べないときは、そこで止めてください（手順 7）。

必要なもの: 学校用の Google アカウントと、パソコンのブラウザ。先に「Firebase の準備の手順書」（`docs/setup/firebase.md`）を済ませ、データベースの URL（`https://〜.firebasedatabase.app` など）を控えておいてください。

**ファイルの共有について:** この GAS は、ドライブに「授業ログ_接続確認」というフォルダを 1 つ作り、確認用の写真をその中に保存します。ファイルをだれかと共有する設定（リンクの共有など）は変えません。

---

## 1. 新しいプロジェクトを作る

1. ブラウザで https://script.google.com/ を開き、**学校用の** Google アカウントでログインします。右上の丸いアイコンを押すと、どのアカウントか確かめられます。
2. 左上の「新しいプロジェクト」を押します。
3. 画面の上の「無題のプロジェクト」という文字を押します。
4. 「プロジェクトの名前を変更」の欄に `授業ログ 接続確認` と入れて、「名前を変更」を押します。

## 2. コードを貼って保存する

1. 画面の真ん中に `function myFunction() {` で始まる文字が出ています。この文字の上を 1 回押してから、Ctrl キーを押したまま A を押し（すべて選ぶ）、Delete キーで消します。
2. このフォルダの `gas/check/Code.gs` を開き、中身を**すべてコピー**して、消した所に貼ります。
3. 上の「プロジェクトを保存」（フロッピーディスクの形のアイコン）を押します。Ctrl キーを押したまま S を押しても保存できます。

## 3. データベースの URL を入れる

1. 左のはしにある歯車のアイコン（「プロジェクトの設定」）を押します。
2. 「全般設定」の「Chrome V8 ランタイムを有効にする」に**チェックが入っている**ことを確かめます。入っていなければ、チェックを入れます。
3. 下へ進み、「スクリプト プロパティ」の「スクリプト プロパティを追加」を押します。
4. 「プロパティ」に `DATABASE_URL` と入れます（大文字。まちがえないように、ここからコピーしてください）。
5. 「値」に、控えておいたデータベースの URL を入れます。最後に `/` は付けません。
6. 「スクリプト プロパティを保存」を押します。
7. 左のはしの `<>` のアイコン（「エディタ」）を押して、コードの画面に戻ります。

## 4. ウェブアプリとして公開する

1. 右上の「デプロイ」を押し、「新しいデプロイ」を押します。
2. 「種類の選択」の横の歯車のアイコンを押し、「ウェブアプリ」を選びます。
3. 「説明」には `接続確認` と入れます（何でもかまいません）。
4. 「次のユーザーとして実行」は「**自分**（自分のメールアドレス）」を選びます。
5. 「アクセスできるユーザー」は「**全員**」を選びます。
   - 「全員」が無く、「（学校名）内の全員」などしか選べないときは、**ここで止めて、手順 7 に進んでください。**
6. 「デプロイ」を押します。

## 5. 権限を許可する

はじめて公開するときは、この GAS がドライブと外へのつながりを使ってよいかを聞かれます。

1. 「ウェブアプリを使うには、データへのアクセス権限を付与する必要があります」と出たら、「アクセスを承認」を押します。
2. アカウントを選ぶ画面が出たら、**学校用の** アカウントを押します。
3. 「このアプリは Google で確認されていません」と出たときは、左下の「詳細」を押し、いちばん下の「授業ログ 接続確認（安全ではないページ）に移動」を押します。これは、自分で作ったプログラムなので出る表示です。（この画面が出ずに、次の画面になることもあります。）
   - ここで「管理者がブロックしています」「アクセスがブロックされました」などと出て進めないときは、**そこで止めて、出ている文をそのまま Claude Code に伝えてください。**
4. 「授業ログ 接続確認 が Google アカウントへのアクセスをリクエストしています」という画面に、許可する内容が並びます。次の 2 つが出ます。
   - 「Google ドライブのすべてのファイルの表示、編集、作成、削除」（フォルダを作り、写真を保存するため）
   - 「外部サービスへの接続」（Firebase に本人確認を問い合わせるため）

   項目の横にチェックの欄があるときは、「すべて選択」にチェックを入れます。
5. 「許可」（または「続行」）を押します。

## 6. URL を Claude Code に伝える

1. 「デプロイを更新しました」（または「新しいデプロイ」）の画面に、「ウェブアプリ」の URL が出ます。`https://script.google.com/macros/s/` で始まり、`/exec` で終わる長い文字です。
2. その下の「コピー」を押してから、「完了」を押します。
3. 確かめ: ブラウザの新しいタブに、コピーした URL を貼って開きます。`{"ok":true,"version":"check-1"}` と出れば、公開できています。
4. この URL を Claude Code に伝えてください。

この URL は、公開してよい値です。ファイルを守るのは、GAS の中の本人確認です。

## 7. 「全員」を選べなかったとき

手順 4 で「アクセスできるユーザー」に「全員」が無かったときは、公開しないで止めてください。そして、次のことを Claude Code に伝えてください。

- 「アクセスできるユーザー」に出ている選択肢を、**すべて、画面に出ている文のまま**（例: 「自分のみ」「（学校名）内の全員」「Google アカウントを持つ全員」）。
- 「次のユーザーとして実行」に出ている選択肢。

これが、段階 0 でいちばん確かめたい点です。「全員」を選べないときの進め方は、そのあとで相談します。

---

## コードを直したあとに公開し直す

Claude Code が `gas/check/Code.gs` を直したときは、次のように更新します。URL は変わりません。

1. 手順 2 のとおりに、コードの画面の文字をすべて消して、新しい `gas/check/Code.gs` の中身を貼り、「プロジェクトを保存」を押します。
2. 右上の「デプロイ」を押し、「デプロイを管理」を押します。
3. 左の一覧で、手順 4 で作ったデプロイ（`接続確認`）が選ばれていることを確かめ、右上の鉛筆のアイコン（「編集」）を押します。
4. 「バージョン」の欄を押して、「新バージョン」を選びます。
5. 「デプロイ」を押し、「完了」を押します。

「新しいデプロイ」を押すと、URL が変わってしまいます。直したときは、必ず「デプロイを管理」から更新してください。

## 確認が終わったら

確認用の写真は、確認ページから片付ける（ゴミ箱に入れる）ことができます。ドライブの「授業ログ_接続確認」フォルダは、確認がすべて終わってから、先生が自分で消してかまいません。
