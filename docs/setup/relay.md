# 中つぎ（Cloudflare Workers）を置く手順

学校の回線では、`script.google.com` への通信だけが止められていて、写真・PDF・手書きの保存の仕組み（Google Apps Script）に届きません（2026-11-17 の確認。`docs/reports/stage1b-2-check.md` の最後）。

学校から届く場所に、小さな「中つぎ」を置きます。アプリは中つぎへ送り、中つぎが今の保存の仕組みへ渡します。保存先は、今までどおり先生の Drive です。

```
アプリ（学校の iPad） → 中つぎ（Cloudflare） → 保存の仕組み（Google Apps Script） → 先生の Drive
```

## 知っておくこと

- 中つぎは、何も保存しません。受け取ったものを、そのまま渡すだけです。
- 生徒の写真・PDF・手書きと、ログインの印（トークン。1 時間で切れます）が、Cloudflare の中を通ります。
- 送り先は、今の保存の仕組みの 2 つ（本番用・確認用）だけに決めてあります。ほかの場所へは送れません。
- Cloudflare Workers の無料の枠は、1 日 10 万回までです（2026-11 時点。Cloudflare の案内で確かめてください）。授業で使う分には、足ります。
- 中つぎのアドレスは、秘密ではありません（アプリの中に書きます）。
- パスワードは、Claude Code に伝えないでください。登録とログインは、先生が行います。

## 手順

画面の言葉は、Cloudflare の側で変わることがあります。見つからないときは、Claude Code に画面の言葉を伝えてください。

### 1. Cloudflare に登録する

1. ブラウザで `https://dash.cloudflare.com/sign-up` を開きます。
2. メールアドレスとパスワードを入れて、登録します。届いたメールで、アドレスの確認をします。
3. 料金のプランを聞かれたら、無料（Free）を選びます。カードの登録は要りません。

### 2. 中つぎを作る

1. 左のメニューから「Workers & Pages」（または「Compute (Workers)」）を開きます。
2. 「Create」（作成）→「Worker」を選びます。ひな形を聞かれたら「Hello World」を選びます。
3. 名前を付けます。例: `jugyo-log-relay`（半角の英小文字・数字・`-`）。
4. 「Deploy」（公開）を押します。
5. はじめて作るときは、`○○.workers.dev` の「○○」の部分（自分のサブドメイン）を決める画面が出ます。好きな名前を付けます（本名や学校名は入れないでください）。

### 3. コードを貼る

1. 作った Worker の画面で「Edit code」（コードを編集）を押します。
2. はじめから入っているコードを全部消します。
3. このフォルダの `relay/worker.js` の中身を全部写して、貼ります。
4. 「Deploy」（公開）を押します。

### 4. 動いているか確かめる

1. Worker の画面に出ているアドレス（`https://jugyo-log-relay.○○.workers.dev` の形）を写します。
2. ブラウザの新しいタブで、そのアドレスの後ろに `/ping` を付けて開きます。
   例: `https://jugyo-log-relay.○○.workers.dev/ping`
3. `{"ok":true,"version":"relay-1"}` と出れば、できています。

### 5. アドレスを Claude Code に伝える

`/ping` を付ける前のアドレス（`https://jugyo-log-relay.○○.workers.dev`）を、Claude Code に貼ってください。

Claude Code が、次のことをします。

1. アプリの設定（`js/gas-config.js` の `relayUrl`）にアドレスを入れて、公開する。
2. 家の回線で、接続確認ページがすべて ○ になることを確かめる。
3. 先生に、学校の iPad で接続確認ページを試してもらうお願いをする。

## 学校で確かめること

学校の iPad・学校の回線で、接続確認ページを開きます。

- 「確認を始める」→ 6〜10 番が ○ になる。
- 「どこに届くかを調べる」→「先生が置いた中つぎ」が ○ になる。

× のままなら、学校の回線が、先生の中つぎのアドレスも止めています。そのときは、アプリの設定を元にもどし、別の道（学校に `script.google.com` を許してもらう、など）を相談します。

## 中つぎを直すとき

`relay/worker.js` が変わったときは、「3. コードを貼る」をもう一度行います。Claude Code が、貼り直しが要るときに伝えます。

## やめるとき

1. Claude Code に伝えて、アプリの設定（`relayUrl`）を空にもどしてもらいます。
2. Cloudflare の Worker の画面の「Settings」（設定）から、Worker を消します。
