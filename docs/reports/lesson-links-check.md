# 授業の動画・サイトのリンクの確認結果

公開した版: `dafe6d9`（2026-11-20）。規則（`rules.json`）と GAS は変えていない。

## 決めたこと

| 項目 | 内容 |
|---|---|
| 入れる場所 | 先生の「授業の編集」の「動画・サイトのリンク」。アドレスと名前（名前は空でもよい） |
| 生徒の見え方 | 授業の画面の「先生の資料」の下に一覧が出る。先生が 1 人の記録を見る画面にも出る |
| YouTube の動画 | アプリの中で再生する。枠の下に「うまく再生できないときは、別のタブで開く」がある |
| そのほかのサイト | 別のタブで開く（多くのサイトは、ほかのページの中に表示することを禁じているため） |
| 入れられるアドレス | `https://` で始まるものだけ。500 文字まで。名前は 60 文字まで。1 つの授業に 8 個まで。同じアドレスは 2 回足せない |
| 形のおかしいリンク | 先生の画面では「開けないリンクです（生徒には出ません）」の印を付けて出し、消せる。生徒には出さない |
| ほかのクラスの同じ日の授業 | 自動では付けない（授業ごとに入れる） |
| データの置き場所 | `lessons/<classId>/<lessonId>/links/<linkId>` = `{ url, title, order }`。Drive は使わない |

## 分かっている限界

- 動画の持ち主が、ほかのページでの再生を禁じている動画は、枠の中で再生できない。アプリからは見分けられないので、「別のタブで開く」で開く。
- 再生が終わると、YouTube がほかの動画をすすめることがある（同じチャンネルの動画にしぼる設定にしてある）。枠の中のリンクから、YouTube のページへは移れないようにしてある。
- YouTube 以外の動画（NHK for School など）は、別のタブで開く。
- 規則では、アドレスの形を確かめていない（授業を書けるのは先生だけ。アプリが、足すときと出すときの両方で確かめる）。

## 追加: 授業の画面の枠の高さをそろえた（2026-11-20、公開した版 `9c2927c`）

先生からの依頼。iPad の横向きで、「先生の資料」の枠が「自分の記録」の枠より短く終わっていた。「先生の資料」だけにあった高さの上限と、枠の中のスクロールをなくした。2 列のときは、長いほうの枠に合わせてもう一方ものびる。先生が 1 人の記録を見る画面も同じ動きになる。
