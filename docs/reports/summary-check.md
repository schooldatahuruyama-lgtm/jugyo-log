- まだ確かめていない欄は「未確認」です。自動テストの成功だけで、ブラウザや本番で確認済みとはしません。
- 本名、メールアドレス、パスワード、キー、トークンは書きません。

## 1. 先生の決定（2026-11-15）

- 先生用。先生の「記録」の画面で、その授業の全員の「疑問」と「分かったこと」をまとめる。
- AI を使わない。先生のブラウザの中だけで数える。生徒の文章を外へ送らない。費用をかけない。
- 手書きの記録は、まとめに入れない（人数だけ出す）。

## 2. 作ったもの（Claude Code が決めた動き）

- 理解度のグラフの下に、カード「まとめ（自動）」。
- 書いた人数（文字・手書き・まだ）、重要用語ごとの人数（疑問に多く出た順）、よく出てくる言葉（2 人以上・10 個まで）、理解度が低い生徒の疑問。
- 用語・言葉を押すと、その言葉を書いた生徒の出席番号と文が出る。「まとめをコピー」。
- 「よく出てくる言葉」は、漢字が 2 文字以上続く所と、カタカナが 3 文字以上続く所を数える（ひらがなの言葉は数えない。辞書は使わない）。「今日」「授業」などの 20 語と、重要用語と同じ言葉は除く。
- データベース・規則・GAS は変えていない。新しい通信は無い。

## 6. 気づいたこと・割り切り

- 自然な文章の要約ではなく、集計。「どの言葉でつまずいているか」「同じ疑問が何人いるか」を見るためのもの。
- ひらがなだけの言葉（「なぜ」「どうして」など）は数えない。
- 名簿にいない生徒は、まとめの中では「名簿にいない」とだけ出る（ID は出さない）。複数いると、見分けがつかない。
- 生徒が自分で足した重要用語は、表に入れていない（授業の重要用語だけ）。
