# 記録の書き出し（段階 3）の確認結果

設計書 `docs/superpowers/specs/2026-11-12-jugyo-log-design.md` の 3.1。コミット `cfc10c7`（2026-11-21）。

## 何ができるか

生徒の最初の画面の「記録をまとめて保存」から、年度・単元・授業をえらぶと、その授業の中身を順に並べた読み物ができる。「PDF にして保存する」で印刷の画面を開き、PDF にして自分の Google ドライブに残す。アプリは生徒の Google アカウントに入らない。残した PDF を、アプリに読みこみ直すことはできない。

## 決めた動き（Claude Code が決め、実装の前に先生に伝えた）

| 項目 | 動き |
|---|---|
| えらぶもの | 年度（クラス）→ 単元 →（その単元の）授業。「単元に入っていない授業」もえらべる。「先生の資料も入れる」の印を外せる |
| 入るもの | 日付・授業名、重要用語、先生の資料（写真・PDF・リンクのアドレス）、メモ、自分の写真・PDF、理解度、分かったこと、疑問、先生の返事と「見ました」。手書きと、写真・PDF への書きこみは絵に重ねる |
| 一度に作れる量 | 授業 15 個まで（こえたら、ボタンを押せなくして理由を出す）。絵は全部で 150 枚まで（こえた分は、その場所に印と、上に枚数を出す）。iPad が重くなって止まるのを防ぐため |
| PDF | 1 つにつき、最初の 20 ページと、自分が書きこんだページ。出さなかった分は「残り ○ ページは入っていません。」 |
| 読みこめなかったもの | だまって消さない。その場所に「！ …は読みこめませんでした」の枠、上に件数と「もう一度読みこむ」 |
| 送れていない記録があるとき | 「まだ保存できていない記録が ○ 件あります。その分は、読み物に入りません。」を出す（作るのは止めない） |
| 名前 | 入れない。出るのは、年度・クラス・出席番号・生徒 ID |
| 規則・GAS | 変えていない（生徒が今も読めるものだけを読む） |

## 作り

- `js/export-logic.js`: えらび・ページのえらび方・件数（純粋な関数）。
- `js/export-flow.js`: 1 つの授業の全部の中身を、ここ 1 か所で集める。GAS は同時に呼ばない。PDF は 1 つずつ開いて閉じる。
- `js/export-draw.js`: 絵（JPEG。長辺 1200）を作る。PDF を開く・閉じる処理は、アプリ全体で 1 本の列。
- `js/views/student-export.js`: 画面（`#/export/<classId>`）。読み物と絵は、この画面の間だけ持つ（端末に保存しない）。
- `css/print.css`: 印刷では、ボタン・えらぶ部分・手順を消し、授業ごとに新しいページにする。

## 分かっている限界

- 年度の全部を 1 回では作れない。単元ごと（15 個まで）に分けて作る。
- 絵の数は、作り終わった枚数で数える。上限をこえたあとの PDF は、ページ数が分からないので、印 1 つとして数える。
- リンクは、名前とアドレスの文字だけ（動画の中身は残らない）。
- 残るのは読める形の控え。アプリに読みこみ直すことはできない。
