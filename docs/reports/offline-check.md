## 何ができるか

## 作り

- `sw.js`: アプリのファイルの取り置き。ネットを先に見て、失敗か 5 秒の待ちで取り置きを返す。キャッシュは版ごと。新しい版のファイルがそろうまで、前の版を残す。
- `tools/pages-branch.ps1`: 公開のときに、取り置くファイルの一覧 `app-files.json` を作る。
- `js/offline-net.js`・`js/offline-store.js`: 生徒が読んだデータを取り置き、通信の失敗のときだけ返す。書いた場所の取り置きは消す。書きこみはためない。
- `js/session-memo.js`・`js/session.js`: 前に確かめた生徒（uid と生徒 ID だけ）を覚える。名前・メールアドレス・トークンは入れない。
- `js/offline-warm.js`: 一覧を開いたとき、新しい方から 5 つの授業を先に読む。
- `js/offline-refresh.js`: 保存のあと、その授業の記録を読み直して取り置きを新しくする。
- `js/dev/demo.js`: 練習モードで、`localStorage` の `jugyolog:demo:offline` を `1` にすると、電波なしを試せる。

## 分かっている限界

- 一度も電波のある所で開いていない iPad では、使えない。
- 先に読むのは、新しい方から 5 つの授業。それより古い授業は、一度開いたものだけ。
- 写真・PDF・手書きは、前に開いて iPad に残っているものだけ出る。電波なしでは足せない。
- iPad の Safari は、長く使わないサイトの取り置きを消すことがある（そのときは、電波のある所で開き直す）。
- 練習モードでは、読んだ内容の取り置きはページを読みこみ直すと消える（本番は残る）。
