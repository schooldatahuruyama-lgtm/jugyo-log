## 3. 気づいたこと

- 本番の規則（`docs/setup/rules.json`）は、2026-11-13 に Claude Code が Firebase のコンソールで貼って公開した。先生のアカウントと `teacherList` は、先生が登録した。
- ログインなしで外から読むと、`gen/<生徒 ID>` は読め、`gen` 全体・`teacherList`・`classes` は読めない（期待どおり）。
- 規則の確認を 1 回行うごとに、確認用のアカウント（`s00-999.gN`）が Authentication に 1 つ増える。
- 動作確認用に作ったもの: クラス「（動作確認用）テスト組」（2026 年度）、生徒 ID `s26-001`〜`s26-003`。本番で使い始める前に、残すか消すかを先生に確かめる。
- 接続確認ページの時間（保存 6.5 秒など）は、同じパソコンでの前回（5.3 秒）より少し長い。原因は調べていない（回線か GAS の混み具合と思われる。推測）。
