# 授業ログ 段階 1b-2（手書き）の計画

**目的:** 生徒が、メモ・分かったこと・疑問の 3 つの欄に、手書きでも書けるようにする。先生は、それを記録の画面で見られる。

**もとにするもの:** 要件定義書 `docs/requirements.md`（自由メモ・共通の振り返りは、文字入力と手書きの両方）、設計書 `docs/superpowers/specs/2026-11-12-jugyo-log-design.md` の 5.3（GAS の使い方）・7.3・7.4・7.6。見本は `.superpowers/brainstorm/6260-1794483811/content/tegaki-mihon.html`（2026-11-15 に先生が「この形で進めて」と決定。定規は先生の追加の要望）。

**この計画の範囲:** 手書き（メモ・分かったこと・疑問）。写真・PDF の上への書きこみ、オフラインでの詳しい動きは入れない。

## 決めたこと

先生の決定:

- 3 つの欄それぞれに「文字｜手書き」の切りかえ。両方の中身は別々に残る。
- 「動かす／書く」の切りかえ。「書く」は指でもペンでも書ける。「動かす」は指では書けず、画面を上下に動かせる。
- 道具: 黒・赤・青、細い・太い、定規、消しゴム（線ごと）、1 つ戻す、全部消す（確かめを出す）。「＋ 下に書く場所を足す」。紙にはうすい横線。
- 定規: 押している間は、書き始めの点から今の点までの直線になる。

Claude Code の判断:

- 開いたときは「動かす」。ペン（Apple Pencil）は「動かす」のままでも書ける。ペンで書いている間は、手のひら（指の接触）では線を引かない。
- 定規: ほぼ横・ほぼ縦（5 度以内）はぴったりにそろえる。定規は、外すまで続く。消しゴムと定規は、どちらか一方。
- 開いたときに出す側: その欄に手書きがあって文字が空なら「手書き」、それ以外は「文字」。出していない側に中身があるときは、切りかえのボタンに「●」を付ける（黙って隠さない）。
- 「1 つ戻す」は、線を足す・消しゴム・全部消す、のどれも 1 つ戻せる（30 回まで）。
- 上限: 1 つの欄に、線は 2000 本まで、紙の長さは 10 枚ぶん（高さ 4000）まで、データは 250,000 バイトまで。こえるときは、書けなくして、その欄の下に文を出す（黙って捨てない）。
- 保存: 線の座標（幅 800 の座標、小数 1 けた、間引き済み）を JSON にして、GAS を通して先生の Drive（「授業ログ_生徒」）に置く。1 つの欄につき 1 ファイル。保存のたびに新しいファイルを作り、目録を書きかえ、古いファイルをゴミ箱に入れる。
- 保存の時: 最後の線から 3 秒たち、かつ前の保存の始まりから 30 秒以上あいたとき。授業ページを離れるときにも保存する。保存までの間は、端末の中に下書きを残す。
- 目録: `records/<c>/<l>/<sid>/ink/<memo|learned|question>` = `{ fileId, bytes, strokes, updatedAt }`。
- 先生の一覧用の小さい画像: `inkThumbs/<c>/<l>/<learned|question>/<sid>`（データ URL、20000 文字まで）。添付の小さい画像（`recThumbs`）とは別の場所に、欄ごとに分けて置く（先生の一覧が、今出している欄の全員分だけを 1 回で読めるように）。メモの手書きは一覧に出さないので、小さい画像を作らない。先生の記録の一覧は、これを出す（GAS を呼ばない）。1 人の記録の画面では、Drive から線を取り出して、大きく出す。
- 「全員分をコピー」には、「（手書き N 件は含まれていません）」を添える。
- GAS は `app-3` にする（`putStudentFile` が `application/json` を受ける）。規則に `ink` と小さい画像のキーを足す。

## 端の場合

- 不正な入力: 形のおかしい線のデータ（数でない座標、範囲外、知らない色）は、読むときに落とす。こわれた JSON のファイルは、「手書きを読みこめませんでした。」と「もう一度」を出す（空として上書きしない）。
- 重複と境界: 上限ちょうどまでは書ける。1 本もない手書きは、目録と小さい画像を消し、ファイルをゴミ箱に入れる。同じ保存を 2 回送っても、ファイルは 1 つ（端末が作ったキー）。別の端末のほうが新しいときは、下書きで上書きしない（文字の下書きと同じ決まり）。
- 違反や失敗の見せ方: 保存の失敗は、今ある保存の状態の文（「保存できていません」）と、離れるときの確かめで見せる。上限・読みこみの失敗は、その欄の下の文で見せる。
