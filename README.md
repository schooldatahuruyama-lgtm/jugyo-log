# 授業ログ

授業 1 回ごとに、先生の板書・配布資料と、生徒自身のメモ・写真・振り返りを 1 か所に残すアプリです。

## いまの状態

段階 0（接続確認）は終わりました。段階 1a（ログイン・名簿・授業と資料・文字の記録・先生の記録確認）に続き、段階 1b-1（生徒の写真・PDF の添付）の機能を追加しました。手書きは、今後の予定です。段階 1b-1 のブラウザ・本番・学校の iPad での確認は、まだです。[段階 1b-1 の確認結果](docs/reports/stage1b-1-check.md) に確認項目をまとめています。これまでの結果は [段階 1a-3 の確認結果](docs/reports/stage1a-3-check.md) と [段階 1a-4 の確認結果](docs/reports/stage1a-4-check.md) にあります。

## 段階 1a-1 の使い方

### 先生の作業（最初の 1 回）

1. `docs/setup/firebase.md` の「9. 本番の規則を貼る」を行います。
2. 同じ手順書の「10. 先生のアカウントを作る」を行います。パスワードは Claude Code に伝えません。
3. 終わったら Claude Code に知らせます。Claude Code が、アプリを公開します。

### 先生がすること

1. 公開されたページを開き、先生のメールアドレスとパスワードでログインします。
2. 最初に、クラスの画面のいちばん下の「規則の確認へ」を押し、「規則の確認を始める」を押します。すべて ○ になるか確かめます。× があれば、生徒に使わせる前に「結果をコピー」で Claude Code に知らせます（規則を貼りかえたときは、毎回行います）。
3. 「クラスを作る」で、年度とクラスの名前を入れてクラスを作ります。
4. 「生徒 ID を発行する」で、入学年度と人数を入れて発行します。
   - **ID の発行は、1 つの画面（1 つのタブ）で行います。2 つの画面で同時に発行しないでください。**
   - 1 時間に作れる数には上限があります。途中で止まったら、1 時間ほどあとで「続きを発行する」を押します。
5. クラスを開き（名簿）、「生徒を足す」で生徒 ID を選び、出席番号を入れて保存します。
6. 名簿の「ID の一覧を印刷する」で、ID と最初のパスワードの一覧を印刷し、1 人分ずつ切って配ります。
7. 生徒がパスワードを忘れたときは、名簿でその生徒の「パスワードを出し直す」を押します（古いパスワードでは入れなくなります）。

### 生徒がすること

1. 配られた紙のページを開き、生徒 ID と最初のパスワードでログインします。
2. メニューの「パスワードを変える」で、自分だけのパスワードに変えます。

### 練習モード

パソコンで `http://localhost:…/?demo=1` を開くと、本物の Firebase を使わない練習モードになります（データはそのパソコンの中だけ）。練習モードでは、規則の確認はできません。

確認の結果は `docs/reports/stage1a-1-check.md` に書き残します。

## 段階 1a-2 の使い方

### 先生の準備

1. [Firebase の手順書「9. 本番の規則を貼る」](docs/setup/firebase.md#9-本番の規則を貼る段階-1a) をもう一度行います。段階 1a-2 では、先生が授業全体を読めるように規則が変わっています。最新の `docs/setup/rules.json` をすべて貼り直して「公開」を押します。
2. [GAS の手順書「本番用の GAS を公開する」](docs/setup/gas.md#本番用の-gas-を公開する) を行います。確認用とは別のプロジェクトに `gas/Code.gs` を貼って公開し、`/exec` で終わる URL を Claude Code に伝えます。Claude Code が `js/gas-config.js` の `appUrl` に入れます。本番用のコードを更新するときは、同じ手順書の「本番用のコードを直したあとに公開し直す」に従います。
3. アプリが公開されたら、先生としてログインし、「規則の確認」を実行します。段階 1a-3 では、授業・資料・単元の 10 項目と、生徒の記録の 15 項目を含む **44 項目すべてが ○** になり、準備・片付けの失敗が出ていないことを確かめます。× があれば「結果をコピー」で Claude Code に知らせます。規則を直して貼り直したときは、毎回この確認を行います。

### 単元 → 授業 → 資料の順に作る

1. 「単元」を開き、年度を選んで「単元を作る」を押します。名前を入れて作ります。作った単元は「名前を変える」「上へ」「下へ」で直したり、並べ替えたりできます。
2. 「授業」を開き、「授業を作る」を押します。日付・授業名・単元・対象のクラスを選んで作ります。クラスを複数選ぶと、それぞれに別の授業ができます。単元は「（なし）」でも作れます。
3. 作った授業を開き、「写真を足す」または「PDF を足す」を押してファイルを選びます。種類（板書／配布資料）と資料の名前を決めて「足す」を押します。同じ年度のほかのクラスに同じ日の授業があれば、その授業にも同じ資料を付けられます。
4. 資料を押すと大きく表示できます。写真は拡大・縮小、PDF はページ送りができます。「上へ」「下へ」で資料の順番を変え、「消す」でその授業から外せます。

PDF は 1 つ 10MB まで、資料は 1 つの授業につき 12 個までです。同じ資料を複数の授業に付けた場合、最後の授業から外すまで Drive のファイルは残ります。生徒の記録がある授業は消せません。ファイルは Drive の「授業ログ_資料」に保存され、共有の設定は変えません。

練習モードでは本物の Firebase や Drive を使わずに操作を試せます。本番用 GAS の保存・取り出しと規則の確認は、公開したアプリで別に確かめます。確認の結果は [段階 1a-2 の確認結果](docs/reports/stage1a-2-check.md) に書き残します。

## 段階 1a-3 の使い方

### 生徒: 一覧 → 授業 → メモと振り返り

1. 生徒 ID でログインすると、授業の一覧が出ます。「年度」で年度とクラスを選びます。同じ年度にクラスが 2 つある場合も、それぞれ選べます。画面にはクラス名と自分の出席番号が出ます。
2. 「日付順」または「単元別」で授業を探します。日付順は「これから」「今週」「先週」、それより前は月ごとに並びます。小さい画像が複数あるときは、左右の矢印か、指を横にすべらせる操作で切り替えます。授業を軽く押すと開きます。
3. 「先生の資料」で板書や配布資料を見ます。写真や PDF を押すと大きく表示できます。横向きでは資料が左、自分の記録が右です。縦向きでは資料が上、記録が下になります。
4. 「自分の記録」の「メモ」に書きます。「振り返り」では「今日の理解度」を 4 つから選び、「分かったこと・学んだこと」「疑問・まだ分からないこと」を書けます。すべてを埋める必要はありません。理解度は選び直せますが、選んでいない状態には戻せません。
5. 文字は 1 つの欄につき 2000 文字までです。残り 200 文字から、あと何文字書けるか出ます。変更して約 2 秒後に自動で保存します。上の「保存しました」を確かめます。
6. 「一覧へ」で戻ります。理解度を選ぶと、授業の印が「記録あり」になります。メモだけを書いた場合は「振り返りがまだ」のままです。授業を開き直すと、保存した内容を読めます。

### 保存の見方

| 表示 | 意味・すること |
|---|---|
| 保存中… | 変更を保存しています。「保存しました」になるまで待ちます。 |
| 保存しました | サーバーに保存できました。 |
| 保存できませんでした。もう一度ためしています… | 自動で送り直しています。失敗後、2 秒・5 秒・15 秒の間隔でやり直します。 |
| 保存できませんでした | 電波を確かめて「もう一度」を押します。授業が消されたり、クラスから外れたりした場合は自動ではやり直しません。先生に知らせます。 |
| 接続が切れています | ネットにつながっていません。書いた内容は、使える場合はこの iPad に下書きとして残します。 |
| 一覧の「まだ保存できていません」 | 送れていない下書きがあります。通信が戻ってから一覧を開き直すと、送り直します。 |

「一覧へ」を押したときに送れていない変更があれば、先に保存します。保存できなければ、この iPad に残して戻るか、確認が出ます。下書きは、保存できたら消します。ほかの端末であとから保存した記録がある場合は、その記録を残し、古い下書きを捨てます。

「この iPad に下書きを残せません」と出た場合は、「保存しました」になるまでページを閉じないでください。iPad でタブを閉じたり、ほかのアプリに移ったりする前にも、保存の表示を確かめます。

ログアウトすると、下書きと、取り置いた資料・小さい画像を消します。送れていない記録がある場合は、ログアウトの確認に件数が出ます。残したい内容は、先に保存を済ませます。

先生は、公開後に「規則の確認」の **44 項目すべてが ○** になることと、準備・片付けの失敗がないことを確かめます。確認用の記録は、生徒として消してから授業を片付けます。ブラウザ・接続確認ページ・Drive・学校の iPad での確認結果は、[段階 1a-3 の確認結果](docs/reports/stage1a-3-check.md) に書き残します。

## 段階 1a-4 の使い方

先生が生徒の記録を読む画面を追加しました。ブラウザ・公開後・学校の iPad での確認は、[段階 1a-4 の確認結果](docs/reports/stage1a-4-check.md) に書き残します。まだ確認していない項目は「未確認」です。

### 生徒の記録を見る

1. 先生の上部のメニューで「記録」を押します。授業の編集にある「生徒の記録を見る」からも開けます。
2. 「年度」→「クラス」→「授業」の順に選びます。最初は今の年度の最初のクラスで、今日以前のいちばん新しい授業が出ます。今日以前の授業がなければ、いちばん新しい授業が出ます。選び直したクラスと授業はページの URL に残ります。
3. 理解度のグラフで、4 段階と「まだ入力なし」の人数、全体の人数を見ます。書きかけも一覧に出ます。名簿から外した生徒の記録も「名簿にいない」と付いて最後に残り、人数に含まれます。
4. 「疑問／分かったこと」と「理解度が低い順／出席番号順」を切りかえます。手書きは文章の下に小さい画像で出ます。画像がないときは、行を開くと見られる案内が出ます。文章も手書きもないときだけ「（まだ書いていません）」と出ます。
5. 一覧の行を押すと、その生徒の資料・メモ・理解度・振り返りを読めます。「前の人」「次の人」は出席番号順です。名簿にいない生徒は最後です。「‹ 一覧へ」で同じ授業の一覧に戻れます。
6. 最新の記録を見たいときは、一覧の「読み直す」を押します。自動では読み直しません。先生の画面では、生徒の記録を書きかえたり消したりできません。「提出」の操作もありません。

1 人の記録では、メモ・分かったこと・疑問の手書きを文章の下に表示します。書く道具は出ません。読みこめない欄は「もう一度」で試せます。一覧の小さい画像は欄ごとに取り置き、「読み直す」で更新します。

### 全員分の文章をコピーする

1. コピーしたい項目（「疑問」か「分かったこと」）と並び順を選び、「全員分をコピー」を押します。
2. 文章を書いた生徒の分だけを、表示中の順番で、1 人 1 行にしてコピーします。文章の中の改行は空白になり、出席番号や生徒 ID は付けません。「N 人分をコピーしました。」と出たら、使いたい場所に貼り付けます。
3. 文章がなければ「コピーする文章がありません。」と出ます。端末でコピーできないときは、画面に出る欄の文章を選んで手でコピーし、「閉じる」を押します。

手書きがあると、コピーした文章の末尾に「（手書き N 件は含まれていません）」が付き、コピー後の知らせにも件数が出ます。手書きだけの場合はコピーせず、「コピーできる文章がありません（手書き N 件）。」と知らせます。

## 段階 1b-1 の使い方

### 生徒: 自分の写真・PDF を足す

1. 授業ページの、メモと振り返りの間にある「自分の写真・PDF」で「＋ 写真・PDF」を押します。iPad では、写真を撮る・写真から選ぶ・ファイルから選ぶ操作ができます。1 回に 1 つずつ足します。
2. 写真は送る前に長辺 1600px 以下に縮めます。PDF は 1 つ 10MB までです。写真と PDF 以外は足せません。もとのファイル名は保存せず、「写真 1」「PDF 1」のように表示します。
3. 送っている添付には「送っています…」と出ます。送っている間も、メモや振り返りは書けます。送れたものは小さく並び、押すと大きく表示できます。PDF はページを送れます。小さい画像が作れない場合は「写真」「PDF」の文字が出ます。
4. 1 回の授業につき 6 個までです。送っている途中・送れなかったものも、やめるまでは 1 個に数えます。6 個になると「＋ 写真・PDF」は押せません。1 つ消すか、送れなかったものを「やめる」と、また足せます。
5. 「送れませんでした」と出たら「やり直す」を押します。同じ添付として送り直すので、重複して足されません。「この写真は読みこめませんでした。」と出たときは「やめる」を押し、別の写真を選びます。
6. 保存した添付の「消す」を押すと、確認が出ます。消すと元にはもどせません。目録から外し、Drive のファイルをゴミ箱へ入れます。目録の削除に失敗した場合は、その添付を残してエラーを表示します。

送れていないファイルは、ページを開いている間だけ持っています。アプリ内でページを離れるときは、文字の保存確認のあとに「まだ送れていない写真・PDF があります。離れると、送れていない分は消えます。」と確認します。タブを閉じる・ページを読み直す際の確認はブラウザの機能によるため、送信が終わってから操作してください。ファイルの名前や中身を、文字の下書きに保存することはありません。

添付を足す・消す操作でメモや振り返りは変わりません。文字を保存しても添付は残ります。一覧の「記録あり」は、今までどおり理解度を選んだかどうかで決まります。

### 先生: 添付を見る

「記録」の一覧では、添付のある行に「添付 2」のように個数が出ます。行を押すと、その生徒のメモと理解度の間に「写真・PDF」が並びます。押すと大きく表示できます。先生は読むだけで、足す・消す操作はできません。ファイルを開けるのは、持ち主の生徒と先生だけです。Drive のファイルは共有しません。

### 先生の作業: 規則と本番用 GAS を更新する

1. [Firebase の手順書](docs/setup/firebase.md) の「9. 本番の規則を貼る」に従い、最新の [rules.json](docs/setup/rules.json) をすべて貼り直して公開します。生徒の添付・手書きの目録と小さい画像の規則が増えています。
2. [GAS の手順書](docs/setup/gas.md) の「本番用のコードを直したあとに公開し直す」に従い、本番用プロジェクトへ最新の [gas/Code.gs](gas/Code.gs) を貼り、新しい版として同じデプロイを更新します。URL は変えません。確認用の `gas/check/` は変更しません。`ping` が `app-3` を返すことを確かめます。
3. Claude Code がアプリを公開したあと、「規則の確認」の **102 項目すべてが ○** で、準備・片付けの失敗もないことを確かめます。確認用の記録・添付と手書きの目録・削除時刻・小さい画像は、生徒として消してから授業を片付けます。確認用の先生の返事と目印は、先生として一緒に消します。
4. 接続確認ページ・Drive・学校の iPad・ほかの生徒から見えないことを、[段階 1b-1 の確認結果](docs/reports/stage1b-1-check.md) の順に確かめ、結果を記録します。練習モードだけでは、本番の公開範囲を確認したことにはなりません。

追加した規則の確認（先生として読む行を除き、確認用の生徒として行います）:

| 試すこと | 期待 |
|---|---|
| すでにある `attachments/a1` を、同じ `fileId` で書き直す | ok |
| すでにある `attachments/a1` を、別の `fileId` で書きかえる | denied |
| `recThumbs/…/<自分>` に、文字を直接書く | denied |
| 自分の `ink/memo` に、正しい目録を書く | ok |
| 自分の `ink/other` に書く | denied |
| 自分の `ink/memo` に、`strokes` なしで書く | denied |
| 自分の `ink/memo` に、`strokes: 0` で書く | denied |
| ほかの生徒の `ink/memo` に書く | denied |
| 自分の `inkThumbs/…/learned/<自分>` に書く | ok |
| 自分の `inkThumbs/…/memo/<自分>` に書く | denied |
| ほかの生徒の `inkThumbs/…/learned/s00-998` に書く | denied |
| 生徒として `inkThumbs/…/learned` 全体を読む | denied |
| 先生として `inkThumbs/…/learned` 全体を読む | ok |
| 自分の PDF と同じ `on` で `inkPages/a2/p1` を書く | ok |
| 自分の PDF と違う `on` で `inkPages/a2/p1` を書く | denied |
| ページ名が不正な `inkPages/a2/p0` を書く | denied |
| 写真の置き場所に `inkPages/a1/p1` を書く | denied |
| PDF の置き場所に写真の `ink/a2` を書く | denied |
| `inkPages/a2/p1` を前より古い時刻で書く | denied |
| 授業の PDF の資料と同じ `on` で `inkPages/<資料の ID>/p1` を書く | ok |

PDF への書きこみはデータ・保存処理までを追加しています（画面は Task 2）。ページごとの線は別ファイルに保存し、目録は `records/…/inkPages/<場所>/p<N>`、削除時刻は `inkPagesCleared/<場所>/p<N>` に置きます。コードと下書きでは `<場所>#p<N>` を使い、ページ番号は 1〜999、`on` は対象 PDF のファイル ID です。規則の確認では架空の PDF の添付・資料を用意し、Drive にファイルを作らず、確認後に片付けます。

先生の返事（段階 2）では、先生が記録を読みながら返事を書き、生徒が授業ページで読めます。生徒 1 人・授業 1 回につき、400 文字までの文と「見ました」の印を保存できます。どちらかが必要です。先生だけが書け、先生と本人だけが読めます。返事と一覧用の目印は一緒に保存・削除し、授業を削除すると両方を消します。練習モードでも、先生と生徒を切り替えて同じデータを読めます。

返事の規則の確認は 12 項目を追加しています。先生による文・印・目印の保存、生徒本人による読み取りが通ることと、空の返事・401 文字・`seen: false`・生徒の書きこみ・ほかの生徒や授業全体の返事の読み取りが拒否されることを確かめます。通信の応答が失われた場合も先生として片付け、失敗は表の × で知らせます。

手書きは保存・読みこみのしくみを追加した段階です。線の JSON は Drive の「授業ログ_生徒」に欄ごとに保存し、目録は `records/…/ink/<memo・learned・question>`、小さい画像は `inkThumbs/<classId>/<lessonId>/<learned・question>/<studentId>` に置きます。小さい画像は 20000 文字までのデータ URL で、先生は 1 つの欄の全員分を 1 回で読めます。メモの小さい画像は作らず、`recThumbs` は添付の `a1`〜`a6` だけに使います。端末の下書きは文字の下書きと分けて保存し、ログアウト時に消します。入力画面は次の Task で追加します。

## 年度が変わったら

1. 「クラス」で、新しい年度のクラスを作ります。
2. 新しいクラスの名簿を開き、「前の年度のクラスから引きつぐ」で前の年度のクラスを選びます。
3. 新しい出席番号を入れて保存します。生徒 ID は同じものを引きつぎます。
4. 新しい年度の単元と授業を作ります。

前の年度のクラス・授業・記録は消しません。生徒は授業一覧の「年度」で前の学年を見られます。先生も「記録」の「年度」で、前の年度の記録を読めます。

## 段階 0 の記録

段階 0 では、学校の iPad と学校のネットワークから、ログインとデータベース（Firebase）、写真を先生の Google Drive に保存する仕組みが使えるかを確かめます。

## 接続確認の手順（先生がすること）

1. `docs/setup/firebase.md` を開き、書いてある順番に Firebase を準備します。終わったら、データベースの URL とウェブ API キーを控えます。
2. `docs/setup/gas.md` を開き、書いてある順番に GAS（写真を保存する小さなプログラム）を公開します。終わったら、`/exec` で終わる URL を控えます。
3. 控えた 3 つの値（データベースの URL、ウェブ API キー、GAS の URL）を Claude Code に伝えます。パスワードは伝えません。
4. Claude Code が確認ページを公開します。公開できたら、ページの URL を教えてもらいます。
5. 学校の iPad（学校のネットワーク）で、その URL を開きます。「確認している場所」を「学校」にして、「確認を始める」を押します。
6. 終わったら「結果をコピー」を押し、コピーした文章を Claude Code に貼り付けて伝えます。コピーできないときは、画面に出る欄の文章を選んでコピーします。
7. 学校では、合計 3 回確認します（同時に 40 回呼ぶ結果を 3 回分ほしいためです）。2 回目と 3 回目は、ボタンが「もう一度確認する」に変わっているので、それを押します。毎回、6 と同じように「結果をコピー」で伝えます。
8. 家でも、同じページを開いて 5 と 6 をします。「確認している場所」は「家」にします。家は 1 回で大丈夫です。
9. コピーした文章には入らないものを、次の 2 つ、Claude Code に伝えます。
   - Google Drive の空き容量: パソコンで https://drive.google.com/ を開き、学校用のアカウントでログインします。左のメニューの下のほうにある「保存容量」の「○○ GB / ○○ GB を使用中」という文字を見て、そのまま伝えます。確認ページの項目 10 の数字と見比べます。
   - iPad の機種名と iPadOS のバージョン: iPad の「設定」→「一般」→「情報」を開き、「機種名」と「システムバージョン」に出ている文字を、そのまま伝えます。
10. 結果を伝え終わったら、`docs/setup/gas.md` と `docs/setup/firebase.md` の「確認が終わったら」を行います。

結果は `docs/reports/stage0-check.md` に書き残します。

## 重要用語の使い方

- 先生は「授業の編集」の「重要用語」で、20 文字までの用語を 8 個まで付けられます。同じ単元で前に使った用語も、押すと足せます。
- 生徒は「自分の記録」のメモの上で、自分の用語を 8 個まで足せます。「×」の付いた用語を押すと外せます。追加・削除はすぐに保存され、自分の用語は本人と先生だけが見られます。
- 授業の一覧の「用語でさがす」で、用語や授業名の一部から探せます。「まだの授業だけ見る」と一緒に使え、「消す」で検索を解除できます。
- 先生が見る 1 人の記録にも重要用語が表示されます。人の名前など、個人が分かる言葉は入れないでください。

## 開発者向け

### 確認ページの公開

確認ページは、GitHub Pages で公開します。公開の手順は次のとおりです。

1. 最初の 1 回だけ、GitHub に新しいリポジトリを作ります（先生の作業）。Pages を無料で使うには、リポジトリを公開にする必要があります。その場合、`master` に入れたファイル（`docs`、`gas`、`tests`、`.ai-tasks`、`.ai-review` を含む）はすべて見えます。
2. 変更をコミットしてから、次のコマンドで、公開用の `pages` ブランチを作ります（コミット済みのアプリのファイルだけが入ります）。

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File tools/pages-branch.ps1
   ```

3. 2 つのブランチを送ります。

   ```
   git push origin master
   git push origin pages
   ```

4. 最初の 1 回だけ、GitHub のリポジトリで Settings → Pages を開き、Branch を `pages` / (root) にして保存します。

公開したあと、設定の変更が届くまで 10 分ほどかかることがあります。古い表示のままなら、待ってから読み直してください。

公開用のスクリプトは、コミットの印を `js/version.js` と `version.txt` に入れます（作業中の `js/version.js` は `dev` のまま）。本番では、画面の移動やタブへ戻ったときに、5 分以上の間隔で新しい版を確かめ、上の帯で知らせます。「読みこみ直す」は、書きかけの保存・離れる確認のあと、画面のファイルを取り直して更新します。練習モードと `dev` では確かめません。
はじめの読みこみや画面のファイルの取得に失敗したときは、電波の確認を促す文と「もう一度」ボタンを出します。

### 生徒の手書き

メモ・分かったこと・疑問は、ラベルの横の「文字｜手書き」で切りかえます。両方の内容は残り、隠れている側に書いてあると「●」が出ます。
手書きは自動保存されます。「保存できませんでした」が出たら、上の「もう一度」で送り直せます。
保存できないまま一覧へ戻る場合は確認が出ます。手書きの下書きはこの端末に残り、次に一覧を開くと送り直します。端末に残せない旨の注意が出た場合は、「保存しました」と出るまでページを閉じないでください。

### 写真・PDF への書きこみ

写真と PDF は、表示の枠の上で指 2 本を開く・閉じると 100〜400% に拡大・縮小でき、2 本の指を一緒に動かすと表示も動きます。「－」「＋」ボタンや、Ctrl（Mac は ⌘ も）を押しながらのホイールでも拡大・縮小できます。PDF はページをめくると 100% に戻ります。「書く」で 2 本目の指が触れると、書きかけの線を取り消して拡大・縮小に切り替わり、指を全部離すとまた書けます。ペンで書いている間は、指では拡大しません。

先生の資料の写真と、自分で足した写真は、大きく開いて「✎ 書きこむ」を押すと、手書きと同じ道具で上に書けます。PDF も同じで、書きこみはページごとに保存します。元の写真は変えず、書きこみは生徒ごとに別に保存します。見られるのは本人と先生だけです。書きこみのある写真には「✎ 書きこみあり」の印が出ます。自分の写真を消すと、その写真への書きこみも消えます。先生は、1 人の記録で写真を開くと、書きこみを見られます（書けません）。確認の結果は [写真への書きこみの確認結果](docs/reports/picture-ink-check.md) にあります。

### 先生の返事

先生は「記録」で生徒を開き、振り返りの下の「先生から」に返事を書いて「保存する」を押します。400 文字までで、「見ました」の印だけでも保存できます。まだ記録を書いていない生徒にも返事を送れます。一覧には「💬 返事ずみ」または「✓ 見ました」が出ます。

生徒は、授業一覧の「💬 先生から」を目印に授業を開き、振り返りの下で返事を読めます。先生が「返事を取り消す」を押すと、生徒の画面から消えます。返事は自動保存されません。書きかけで移動すると確認が出るので、残すときは「もどって保存する」を選びます。

### テスト

```
npm test
```

Node.js 組み込みのテストランナー（`node --test`）で `tests/*.test.js` を実行します。依存パッケージはありません。ビルドもありません。
