# 実装指示書: 先生の記録の画面のグラフを 1 本の帯にする・押してしぼりこむ・授業の一覧に記録の数を出す

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

先生（ユーザー）が、見本を見て承認した（2026-11-15）。見本は `.superpowers/brainstorm/6260-1794483811/content/teacher-ui-ideas.html`（読めなければ、下の文のとおりに作ればよい）。

- G: 理解度のグラフを、4 本の棒から **1 本の帯**にする。帯の中の区切りの長さが割合。数字は **%**（「人」は出さない。「全部で N 人」も出さない）。「まだ入力なし」は 1 番右で灰色。**帯の区切りを直接押すと、その理解度の生徒だけが一覧に並ぶ**（帯の下にボタンは置かない）。
- H: 一覧の行の左はしに、理解度の色の線を付ける。
- I: 授業の一覧の行に「記録 24 / 30 人」と「記録を見る ›」を出す。

（要件定義書 `docs/requirements.md` の「先生の閲覧」。設計書 7.6 の、グラフ・一覧・コピー・1 人の記録を開く、は変えない。変えるのはグラフの形と、上の 3 つ。）

## 変えるファイル

`js/review-logic.js`、`tests/review-logic.test.js`、`js/views/teacher-review.js`、`js/views/teacher-lessons.js`、`css/base.css`（色の変数を足すだけ）、`css/app.css`。ほかのファイルは変えない。

### 1. `js/review-logic.js`

- `levelShares(counts) → [{ key, count, percent }]`。`counts` は `levelCounts` の結果。`key` は `4`・`3`・`2`・`1`・`'none'` の順（この順で返す。0 人のものも返す）。`percent` は整数で、**足すと必ず 100**（0 人のものは 0。四捨五入のずれは、端数の大きい順に 1 ずつ配って合わせる。同じ端数なら、上の順で先のものに配る）。`total` が 0 のときは、全部 `percent: 0`。
- `filterRows(rows, levelKey) → rows`。`levelKey` が `null` なら全部。`4`〜`1` ならその理解度の行、`'none'` なら理解度が入力なしの行。知らない値は全部。もとの配列を変えない。

### 2. `js/views/teacher-review.js`（G・H）

- 「理解度」の枠: 今の棒 5 本と「全部で N 人」をやめ、**1 本の帯**にする。
  - 帯は、`levelShares` の `count` が 1 以上のものだけを、左から `4`・`3`・`2`・`1`・`'none'` の順に並べた `<button>` の列。それぞれの幅は人数の割合（`flex-grow` に人数）。ただし、**どの区切りも幅 56px 以上**（指で押せる幅）。高さ 52px。帯の外側は角を丸くし、区切りの間は白い細い線。
  - 区切りの中の文字は `30%` のような % だけ。区切りの色は下の変数。文字の色は、背景とのコントラストが取れる色（濃い緑・赤は白い文字、うすい緑・オレンジ・灰色は濃い文字）。
  - 読み上げの名前（`aria-label`）は「よく分かった 30%」のようにする。`aria-pressed` で、選んでいるかを伝える。選んでいる区切りには、紺色の太い内側の枠を付ける。
  - 押すと、その理解度でしぼりこむ。同じ区切りをもう一度押すと、全員に戻る。
  - 帯の下に、**色の説明だけ**を小さく並べる（色の四角と名前。5 つ全部。押せない。`<ul>` など）。
  - 生徒が 0 人のときは、帯を出さず「このクラスには、まだ生徒がいません。」（今の文のまま）。
- 一覧の上に、今のしぼりこみを 1 行で出す（`role="status"`）: 全員のときは何も出さない。しぼりこんでいるときは「『あまり分からなかった』の 3 人を出しています。」と、ボタン「全員を出す」。
- 一覧: `filterRows` を通した行を出す。並び順・項目の切りかえ（疑問／分かったこと、理解度が低い順／出席番号順）は今のまま、しぼりこみと組み合わせて働く。しぼりこんだ結果が 0 行になることは無い（0 人の区切りは帯に無い）が、読み直しで 0 人になったら、しぼりこみを外す。
- **「全員分をコピー」は、今出している行（しぼりこんだ行）の分をコピーする。** できたときの文「N 人分をコピーしました。」はそのまま。
- 行の左はしに、理解度の色の線（幅 6px）を付ける（H）。文字の印（`statusChip` と `levelLabel`）は今のまま出す（色だけで伝えない）。
- クラス・授業を切りかえたら、しぼりこみを外す。ハッシュには残さない。

### 3. 色（`css/base.css` に足す）

| 変数 | 値 | 意味 |
|---|---|---|
| `--lv4` | `#14694B` | よく分かった（白い文字） |
| `--lv3` | `#7CC0A0` | 分かった（濃い文字 `#0E3B2A`） |
| `--lv2` | `#E9B44C` | あまり分からなかった（濃い文字 `#3A2A00`） |
| `--lv1` | `#C8402F` | 全然分からなかった（白い文字） |
| `--lv0` | `#C5CAD6` | まだ入力なし（濃い文字 `#2B2F3A`） |

文字と背景のコントラストが 4.5:1 に足りないと思ったら、文字の色を濃くして、報告に書く（背景の色は変えない）。今ある `.review-bar-…` の色の指定は、使わなくなるので消してよい。

### 4. `js/views/teacher-lessons.js`（I）

- 授業の行に、「記録 24 / 30 人」（何か書いた生徒の数 / そのクラスの名簿の人数）と、ボタン「記録を見る ›」（`ctx.navigate('t-review', { classId, lessonId })`）を足す。授業名の所を押すと授業の編集へ（今のまま）。「消す」も今のまま。
- 名簿の人数は、クラスを選んだときに `repo.getMembers(classId)` を 1 回読む。記録の数は、行が画面に入ってから `repo.countRecords(classId, lessonId)` を読む（`IntersectionObserver`。無い端末では、すぐ読む。授業ごとに 1 回だけ。同時に読むのは 4 つまで）。読む前は「記録 … / 30 人」、読めなかったら「記録 ? / 30 人」（黙って 0 にしない）。名簿を読めなかったら、分母を出さず「記録 24 人」。
- クラスを切りかえたら、前のクラスの読みこみの結果は捨てる。画面を離れたら、見張りを外す。
- 読みこみが、授業の一覧の表示や操作（作る・消す・開く）を止めない。

## 端の場合

- 不正な入力: `levelShares` は、`counts` が `null`・数でない値を含んでいても落ちない（0 として扱う）。`filterRows` は、`rows` が配列でないとき `[]`。
- 重複と境界: 全員が同じ理解度（区切り 1 つ・100%）。1 人だけのクラス（100%）。3 人で 1 人ずつ（33・33・34 のように、足して 100）。30 人中 1 人（3%）の区切りも、幅 56px 以上で押せる。区切りを続けて押しても、選ぶ・外すが交互に正しく働く。記録が 0 件の授業は「記録 0 / 30 人」。名簿が 0 人のクラスは「記録 0 / 0 人」。
- 違反や失敗の見せ方: 記録の数を読めないときは「?」を出す。記録の画面の読みこみの失敗は、今までどおり「つながりません。もう一度ためしてください。」。しぼりこみ中であることは、一覧の上の 1 行と、帯の区切りの枠で見せる（気づかずに一部だけを見ている、とならないように）。

## 追加・変更するテスト（`tests/review-logic.test.js`）

- `levelShares`: `{4:9,3:11,2:3,1:1,none:6,total:30}` → `[30, 37, 10, 3, 20]`。`{4:1,3:1,2:1,1:0,none:0,total:3}` → 足して 100（`[34, 33, 33, 0, 0]`）。全部 0 → 全部 0。1 つだけ → 100。`null` → 全部 0。どの場合も、0 人のものは 0%・1 人以上のものは 1% 以上になるとは限らない（とても小さい割合は 0% になりうる）ことは、そのままでよい。
- `filterRows`: `null` → 全部。`2` → 理解度 2 の行だけ。`'none'` → 入力なしだけ。知らない値 → 全部。もとの配列を変えない。配列でない → `[]`。
- 画面のテストのファイルは足さない。`npm test` がすべて成功し、変えた `.js` は `node --check` が通ること。
- 代役の `ctx` を使った手元の実行で、次を確かめて報告に書く: (1) 帯の区切りを押すと、一覧がその理解度だけになり、もう一度押すと戻る。(2) しぼりこみ中の「全員分をコピー」が、しぼりこんだ行だけをコピーする。(3) 授業の一覧の行に「記録 N / M 人」が出て、「記録を見る ›」で記録の画面へ移る。

## 守ること

- `git add`・`git commit` はしない。
- 先生は、生徒の記録を書かない・消さない（読むだけ）。記録を書く・消す通信を足さない。
- コピーの文に、出席番号・生徒 ID を入れない（今のまま）。
- 画面に出す文字は `textContent` で入れる。`innerHTML` を使わない。
- データベースの形・規則・GAS は変えない。生徒の画面は変えない。
