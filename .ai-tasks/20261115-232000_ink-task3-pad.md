## 部品 `inkPad`

```js
inkPad({ ink, readOnly = false, label, onChange }) → { node, getInk(), setInk(ink), setLocked(locked), destroy() }
```

- `ink`: はじめの手書き（`cleanInk` を通して使う）。`label`: 読み上げ用の名前（例「メモの手書き」）。
- `onChange(ink)`: 中身が変わるたびに 1 回呼ぶ（線を足した・消した・戻した・全部消した・紙を足した）。変わらなかった操作（何も当たらない消しゴムなど）では呼ばない。
- `setInk(ink)`: 外から中身を入れかえる（「1 つ戻す」の履歴は空にする。`onChange` は呼ばない）。
- `setLocked(true)` の間は、書けない・道具を押せない（`disabled`）。`false` で戻る。
- `destroy()` のあとは、画面を書きかえず、`onChange` を呼ばない。付けた待ち受けを外す。

### 紙

- `<svg>` で描く（1 枚の大きな canvas にしない）。`viewBox="0 0 800 <ink.h>"`、幅は入れ物いっぱい、高さは幅に合わせた比（`aspect-ratio` か、幅から計算）。背景は白、うすい横線（高さ 40 の間隔。線の色 `#E8EEF7`）。
- 線は 1 本ごとに `<path>`（`strokePath`。`fill="none"`、色は `CONFIG.ink.colors[c]`、太さは `CONFIG.ink.widths[w]`、端と角は丸）。
- 書いている途中の線は、点が来るたびにその `<path>` だけを書きかえる（全部の線を作り直さない）。
- `<svg>` には `role="img"` と `aria-label`（`label` と、線の本数。例「メモの手書き（線 12 本）」）。

### 道具の並び（`readOnly` のときは出さない）

左から。どれも `<button type="button">`、44×44px 以上、選ばれているものは `aria-pressed="true"`（色だけでなく、枠でも分かるように）。

1. 「動かす」「書く」（どちらか一方。**はじめは「動かす」**）。
2. 色: 黒・赤・青（丸い色の印。`aria-label` は「黒」「赤」「青」）。はじめは黒。
3. 太さ: 細い・太い（大きさのちがう丸。`aria-label` は「細い」「太い」）。はじめは細い。
4. 「定規」（定規の絵と文字）。押すと入り、もう一度押すと外れる。
5. 「消しゴム」。押すと入り、もう一度押すと外れる。**定規と消しゴムは、どちらか一方**（片方を入れると、もう片方は外れる）。色を選ぶと、消しゴムは外れる。
6. 「1 つ戻す」（戻せるものが無いときは `disabled`）。
7. 「全部消す」（赤い文字。線が無いときは `disabled`）。押すと、今ある `confirmDialog`（`js/ui.js`）で確かめる: 題「手書きを全部消しますか？」、文「この欄の手書きを全部消します。「1 つ戻す」で戻せます。」、OK の文字「全部消す」（`danger: true`）。

道具の並びの右（せまいときは次の行）に、今の状態の文を出す（`role="status"`）: 「いま: 動かす（指では書けません。ペンは書けます）」／「いま: 書く（指でもペンでも書けます）」。

紙の下に「＋ 下に書く場所を足す」（`canAddPage` が `false` なら `disabled`）。その下に、知らせの文を出す場所（`role="alert"`。空のときは高さを取らない）。

### 書く・動かす

Pointer Events を使う（`pointerdown`・`pointermove`・`pointerup`・`pointercancel`。書き始めたら `setPointerCapture`）。座標は、`getBoundingClientRect()` から紙の座標（幅 800）に直す。

- **ペン**（`pointerType === 'pen'`）: 「動かす」「書く」のどちらでも書ける。
- **指**（`'touch'`）と**マウス**（`'mouse'`）: 「書く」のときだけ書ける。「動かす」のときは何もしない（ブラウザが画面を上下に動かす）。
- ペンで書いている間（`pointerdown` から `pointerup`・`pointercancel` まで）と、そのあと 500 ミリ秒は、指の接触では線を引かない（手のひらを置いても線が出ないように）。
- 同時に書けるのは 1 本だけ（書いている間に来た別の `pointerdown` は無視する）。マウスは左ボタンだけ。
- `touch-action`: 「書く」のときは `none`。「動かす」のときは `pan-y pinch-zoom`。
- 「動かす」のときにペンで書くと、iPad の Safari は画面も動かそうとする。これを止めるため、`<svg>` に `touchstart`（`{ passive: false }`）を付け、**その接触がペン（`touch.touchType === 'stylus'`）のときだけ** `preventDefault()` する。指のときは何もしない（画面が動く）。
- 線の途中の点は、`getCoalescedEvents()` があれば使う（なめらかにするため）。無ければ、そのイベントの 1 点。
- 定規が入っているとき: 書いている途中の表示は、はじめの点から今の点までの直線（`snapLine` を通す）。
- 消しゴムが入っているとき: 触れた所・なぞった所の線を消す（`eraseAt`）。1 回のなぞり（`pointerdown`〜`pointerup`）で消した分は、「1 つ戻す」1 回でまとめて戻る。
- 書き終えたら（`pointerup`）: `makeStroke` → `addStroke`。`error` があれば、線を足さず、知らせの文を出す（下）。`pointercancel` のときは、その線を捨てる。
- 紙の外に出た点は、紙の端に切りつめる（`cleanStroke` がする）。

### 「1 つ戻す」

- `createHistory(CONFIG.ink.undoMax)` を使う。中身を変える操作（線を足す・消しゴムの 1 なぞり・全部消す・紙を足す）の前の ink を積む。「1 つ戻す」で 1 つ前に戻し、`onChange` を呼ぶ。

### 知らせの文

- `'too-many'`: 「線が多すぎて、これ以上書けません。いらない線を消してください。」
- `'too-big'`: 「この欄は、これ以上書けません。いらない線を消すか、写真にとって「自分の写真・PDF」に足してください。」
- `'too-long'`: 「これ以上は、下に足せません。」
- 次に中身が変わったら（線を消したなど）、文を消す。

### `readOnly`（先生が見るとき・あとの Task で使う）

- 道具・「下に足す」・知らせを出さない。線は引けない。`touch-action` は付けない（ふつうに画面が動く）。線が 1 本も無いときは、紙の代わりに「（手書きはありません）」と出す。

## `js/ink-thumb.js`（先生の一覧のための小さい画像）

```js
inkThumb(ink, { document = globalThis.document } = {}) → string | null
```

- 線が無ければ `null`。
- `inkBounds` で線のある範囲を出し、まわりに 12 の余白を足して（紙の中に切りつめる）、その範囲だけを canvas に描く。横は 320px まで、縦は 240px まで（比を保って縮める）。背景は白。線の色・太さは画面と同じ（太さは縮めた比に合わせるが、1px より細くしない）。
- `canvas.toDataURL('image/jpeg', q)` で作る。`CONFIG.thumb.maxChars`（20000）におさまるまで、`q` を 0.8 → 0.6 → 0.4 と下げ、まだ大きければ大きさを半分にして、もう一度。それでもおさまらなければ `null`。
- canvas を作れない・描けないとき（例外）は `null`（保存そのものは止めない）。

## 見た目（`css/app.css`）

- 道具の並び: 背景 `--mine-bg`、うすい線、角の丸み 12px（上の 2 つの角だけ）。ボタンは白、線 `--soft-line`、太い文字。選ばれているものは、こい線（`--c-navy`、3px）。「動かす／書く」は、選ばれている側をこい色でぬる（`--c-navy`、白い文字）。
- 紙: 道具の並びのすぐ下に、同じ幅で付ける。「書く」のときは、紙のまわりの線をこくして（`--mine`、2px）、書けることが分かるようにする。
- 「＋ 下に書く場所を足す」: 紙のすぐ下に、同じ幅（角の丸みは下の 2 つだけ）。
- 横にはみ出さない（1180×820・820×1180）。道具は、せまいときに折り返す。`readOnly` の紙は、うすい線だけ。

## 端の場合

- 不正な入力: はじめの `ink` がこわれている → `cleanInk` で空・直したものになる。座標が数にならない点（`getBoundingClientRect` の幅が 0 など）は捨てる。
- 重複と境界: 軽くさわっただけ（1 点）でも、点が残る。上限ちょうどまでは書ける。書いている途中に 2 本目の指が来ても、線は 1 本。書いている途中で `setLocked(true)`・`setInk`・`destroy` が来たら、その線は捨てる。「全部消す」の確かめで「やめる」→ 何も変わらない。戻せるものが無いときの「1 つ戻す」は押せない。
- 違反や失敗の見せ方: 上限は、紙の下の文（`role="alert"`）で見せ、線を足さない（黙って捨てない）。今の状態（動かす／書く、定規、消しゴム）は、ボタンの枠・色と、状態の文で見せる。
