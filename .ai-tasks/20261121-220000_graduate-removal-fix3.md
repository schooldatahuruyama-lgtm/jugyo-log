# 実装指示書（修正 3）: 卒業の画面に、規則の確認用の生徒が出る

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。もとの指示書は `.ai-tasks/20261121-190000_graduate-removal.md`。

## 目的

公開後の確認で見つけた点。規則の確認用の生徒（`js/rules-probe.js` の `PROBE_ID` = `s00-999`）が台帳に残っているため、卒業の画面に「2000 年度入学　生徒 1 人」と出て、「この学年の記録を消す」を押せてしまう。先生が見て迷うので、出さない。

## 変える内容

- `js/graduate-logic.js` の `cohorts`: 引数に `exclude`（生徒 ID の配列。既定は空）を足し、その ID の生徒を、どの学年にも入れない（`removed` にあっても入れない）。
- `js/views/teacher-graduates.js` と `js/views/teacher-classes.js`（30 日をすぎた学年の知らせ）: `cohorts` を呼ぶ所で `exclude: [PROBE_ID]` を渡す。
- 名簿の画面（`teacher-roster.js`）の印は変えない。

## 端の場合

- 不正な入力: `exclude` が配列でない → 空として扱う。
- 重複と境界: 台帳に確認用の生徒だけ → 「まだ生徒がいません。」。確認用の生徒が `removed` にあり 30 日をすぎている → 卒業の画面にも、クラスの画面の知らせにも出ない・完全に消し始めない。
- 違反や失敗の見せ方: 変えない。
