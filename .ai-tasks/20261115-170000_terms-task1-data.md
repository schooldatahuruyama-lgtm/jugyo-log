## `js/term-logic.js`（通信をしない）

- `cleanTerm(text) → string`: 前後の空白を取り、中の改行・タブ・続く空白を 1 つの空白にする。文字でなければ `''`。
- `checkTerm(text, { max }) → null | 'empty' | 'long'`（`cleanTerm` したあとで見る）。
- `termKey(text) → string`: 探す・くらべるための形。`cleanTerm` → `normalize('NFKC')`（全角と半角をそろえる）→ 小文字 → カタカナをひらがなに → 空白を全部取る。
- `lessonTerms(lesson) → [{ id, text }]`: `lesson.terms`（`{ termId: 文字 }`）を、`cleanTerm` して空でないものだけ、`id` 順で返す。`lesson.terms` がオブジェクトでなければ `[]`。
- `myTermList(v) → [{ slot, text }]`: `{ t1: 文字, … }` を、`t1`〜`t8` のキーで、`cleanTerm` して空でないものだけ、`slot` 順で返す。
- `freeTermSlot(myTerms, slots) → slot | null`（使っていない最初の置き場所）。
- `mergedTerms(lesson, myTerms) → [{ text, own, slot? }]`: 先生の用語（`own: false`）のあとに、自分の用語（`own: true`・`slot`）。**自分の用語のうち、先生の用語と `termKey` が同じものは出さない**（同じ言葉が 2 つ並ばないように。データは消さない）。先生の用語どうし・自分の用語どうしで `termKey` が同じものは、最初の 1 つだけ。
- `hasTerm(lesson, myTerms, text) → boolean`: 先生の用語か自分の用語に、`termKey` が同じものがあるか。
- `matchLessons(lessons, myTermsByLesson, query) → lessons`: `query` の `termKey` が空なら、`lessons` をそのまま返す。そうでなければ、**授業名・先生の用語・自分の用語のどれかの `termKey` に、`query` の `termKey` が含まれる**授業だけを、もとの順で返す。`myTermsByLesson` は `{ lessonId: { t1: 文字, … } }`（`null` でもよい）。
- `frequentTerms(lessons, myTermsByLesson, limit) → string[]`: 全部の授業の用語（先生・自分）を `termKey` ごとに数え（1 つの授業の中の重なりは 1 回）、多い順に `limit` 個。同じ数なら、新しい授業（`lessons` の順で先）に出たものが先。表示の文字は、最初に見つかった書き方。
- `suggestTerms(allLessons, { classId, lessonId, unitId }, limit) → string[]`（先生の候補）: `allLessons` は `{ classId: { lessonId: 授業 } }`。**同じ `unitId`（空でないとき）のほかの授業**の先生の用語から、この授業にまだ無いもの（`termKey` でくらべる）を、重なりを除いて `limit` 個まで。`unitId` が空なら `[]`。

## 端の場合

- 不正な入力: 用語が文字でない・空白だけ → `''`・`'empty'`。21 文字以上 → `'long'`（画面が断る。規則も断る）。改行を含む → 空白に直す。`lessons`・`myTermsByLesson` が `null`・配列でない → 空として扱う（落ちない）。`slot` が `t1`〜`t8` でない → 通信の前に例外。
- 重複と境界: 20 文字ちょうどは通る。全角「ＡＢＣ」と半角「abc」、「ハンシャ」と「はんしゃ」は、同じ言葉としてくらべる（表示は、書いたまま）。先生の用語と同じ言葉を生徒が足していたら、1 つだけ出す。自分の用語が 8 個あれば `freeTermSlot` は `null`。`matchLessons` は、用語の一部（「反射」で「光の反射」）でも当たる。
- 違反や失敗の見せ方: このタスクに画面は無い。計算の関数は例外を投げず、決めた値を返す。通信の失敗は `NetError` のまま投げる。規則の確認で期待と違った行は `×`。
