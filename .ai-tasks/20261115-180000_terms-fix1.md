# 実装指示書: 重要用語の修正 1（規則の確認の片付け、先生の用語の並び順）

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

1. Codex レビュー `.ai-review/20261114-222401_round1.md` の指摘 1（Medium）を直す: 規則の確認で、確認用の生徒の `terms` の削除だけが通信で失敗しても、そのあと確認用のクラスと所属を消してしまう。次の回は、残っているクラス・所属から片付ける相手を探すので、残った `terms` を見つけられず、ずっと残る。
2. Claude Code がブラウザで見つけた点: 先生が足した重要用語が、足した順ではなく、ばらばらの順で並ぶ（用語の ID がでたらめな文字で、ID の順に並べているため）。**足した順に並ぶ**ようにする。

## 変えるファイル

`js/rules-probe.js`、`tests/rules-probe.test.js`、`js/views/teacher-lesson.js`。ほかのファイルは変えない。

### 1. `js/rules-probe.js`

- 片付けで、確認用の生徒の `terms`（と、今ある `records`・`marks`・`recThumbs`）を消せなかったときは、**そのクラスと所属を消さずに残す**（次の回に、生徒として消し直せるように）。結果には、今までどおり「片付け」の失敗を出す。
- 次の回の、前回の残りの片付けで、残っていたクラスについて、生徒として `terms/<自分>/<classId>` も消す（今ある `records`・`marks` の片付けと同じ所で）。消せたら、先生としてクラスなどを消す。
- 確かめの行の数（63）と文は変えない。

### 2. `js/views/teacher-lesson.js`

- 用語を足すときの `termId` を、**足した時刻の順に並ぶ形**にする: `ctx.now()` を 36 進の文字にして 9 けたにそろえ（先頭を 0 でうめる）、そのあとに `newId(ctx.random, 4)` を付ける（英数字だけ。合わせて 13 文字）。`lessonTerms` は ID の順に返すので、足した順に並ぶ。
- 前の形の ID（でたらめな 12 文字）で入っている用語は、そのままの順で出てよい（まだ本番では使われていない）。

## 端の場合

- 不正な入力: 変えない。
- 重複と境界: 同じミリ秒に 2 つ足しても、うしろの 4 文字で別の ID になる。片付けが 2 回続けて失敗しても、3 回目に消せれば、全部きれいになる。消すものが無い（`terms` を書く前に止まった）ときは、今までどおり片付けが済む。
- 違反や失敗の見せ方: 片付けに失敗したら、結果の「片付け」の行に失敗として出す（黙って続けない）。
