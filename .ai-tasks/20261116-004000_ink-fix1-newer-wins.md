# 実装指示書: 手書きの修正 1（新しいほうを残す・消したことを覚える・読み直し・残ったファイルの片付け）

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

Codex レビュー `.ai-review/20261115-103515_round1.md` の指摘 1〜4 を直す。

決まり（Claude Code の判断）: **書いた時刻（`editedAt`）が新しいほうを残す**。これは、今ある一覧からの送り直し（`resendInkDrafts`）と同じ決まり。授業ページでの自動保存・やり直しにも、同じ決まりを通す。「全部消した」ことも、時刻といっしょに覚えておき、古い下書きで生き返らせない。

## 1. 消した時刻を覚える（データの形・規則・`repo`）

- 新しい場所: `records/<classId>/<lessonId>/<sid>/inkCleared/<field>` = 数（その欄の手書きを空にした時刻）。`field` は `memo`・`learned`・`question`。
- 規則（`docs/setup/rules.json`。`ink` のとなり）:

```json
"inkCleared": {
  ".validate": "newData.hasChildren()",
  "$field": {
    ".validate": "($field === 'memo' || $field === 'learned' || $field === 'question') && newData.isNumber()"
  }
}
```

- `js/repo.js`:
  - `removeInk(classId, lessonId, studentId, field, now)`: 目録（と小さい画像）を消し、同じ update で `inkCleared/<field> = now` を書く。`now` が数でなければ `TypeError`。
  - `setInk(…)`: 目録を書く同じ update で、`inkCleared/<field>` を `null` で消す。
  - `getRecord`・`listRecords` の返す記録に `inkCleared: { memo?: 数, … }` を足す（数でないもの・知らない欄は落とす。無ければ `{}`）。
- 規則の確認（`js/rules-probe.js`）に 2 行足す: 自分の `inkCleared/memo` に数を書く → できる。自分の `inkCleared/other` に数を書く → できない。行の数は 73 → 75。片付けで残さない。README などの数を 75 に直す。`docs/superpowers/specs/2026-11-13-jugyo-log-1a-data.md` に形を足す。

## 2. 新しいほうを残す（`js/ink-logic.js` か `js/ink-flow.js` に計算を 1 つ、`js/ink-flow.js`、`js/views/parts/ink-field.js`）

- 計算: `serverInkTime(record, field) → 数`: `record.ink[field].updatedAt` と `record.inkCleared[field]` の大きいほう。どちらも無ければ `0`。記録が `null` でも `0`。
- `saveInkFlow` に、保存の前の確かめを足す。引数に `repo` はすでにある。
  1. `repo.getRecord(classId, lessonId, studentId)` で、今のサーバーの記録を読む。
  2. `serverInkTime(record, field) >= editedAt` なら、**保存しない**で `{ index: record.ink[field] ?? null, superseded: true, record }` を返す（ファイルも上げない）。
  3. それ以外は、今までどおり保存する。`previous` は、引数ではなく、**今読んだ記録の目録**（`record.ink[field] ?? null`）を使う（古い目録をもとに片付けないため）。引数の `previous` は外す。
  4. 空の手書きの保存は、`repo.removeInk(…, editedAt)`。
  - 返す値は `{ index, superseded: false }`。
- `resendInkDrafts` は、自分で記録を読んでくらべるのをやめ、`saveInkFlow` の結果で決める（`superseded` → 下書きを捨てて `dropped`。それ以外 → `sent`）。順番待ち（`queue.run`）の中で行うのは、今のまま。
- `js/views/parts/ink-field.js`:
  - 保存が `superseded` で返ったら: 下書きを消し、保存は成功として扱い（`saved`）、返ってきた記録で `refresh` と同じ読み直しをして、紙をサーバーの中身（消されていれば空）に入れかえる。欄の下に知らせを 1 回出す（`role="status"`）: 「ほかの端末で書いたほうが新しいので、そちらを出しました。」。ただし、待っている間にこの端末でさらに書いていたら（新しい `edit` がある）、紙は入れかえず、その新しい中身の保存を続ける（その `editedAt` は新しいので、ふつうは保存される）。
  - はじめに下書きを使うかどうかの判断も、`serverInkTime` でくらべる（`下書きの editedAt > serverInkTime`）。そのために、`inkField` の引数 `index` に加えて、消した時刻も受け取る（例: `cleared`）。`js/views/student-lesson.js` から渡す。
  - `refresh(index, cleared)`: 保存待ち・保存中でなく、`max(index?.updatedAt, cleared)` が今知っている時刻より新しければ、入れかえる。**目録が無く、消した時刻が新しいとき**は、紙を空にする（今は `refresh(null)` を無視している）。

## 3. 先生の 1 人の記録の「もう一度」（`js/views/teacher-record.js`）

- 手書きの読みこみの「もう一度」は、最初の `fileId` を使い回さず、`repo.getRecord(classId, lessonId, studentId)` で目録を読み直してから、今の `fileId` を読む。目録が無くなっていれば、その欄の手書きの表示を消す（文章も無ければ「（まだ書いていません）」）。
- はじめの読みこみが `notfound` だったときは、自動で 1 回だけ、同じ読み直しをためす（生徒が保存して、ファイルが入れかわった直後のため）。それでもだめなら、今ある文と「もう一度」。

## 4. 目録に入らなかったファイルの片付け（`js/ink-flow.js`・`js/views/parts/ink-field.js`）

- `saveInkFlow` に `onUploaded(fileId)` を足す（あれば、ファイルを上げた直後に呼ぶ）。
- `ink-field` は、上げたファイルの ID を覚えておく。保存が成功したら、覚えているもののうち、**今の目録の `fileId` でないもの**を `files.trashStudent` で片付ける（失敗は無視。片付けをためしたものは、覚えから外す）。`superseded` で終わったときも、同じように片付ける。
- ページを閉じて覚えが消えた分は、片付けない（Drive に小さいファイルが残るだけで、目録からは見えない）。この割り切りを、コードのコメントと `docs/superpowers/specs/2026-11-13-jugyo-log-1a-data.md` に 1 行書く。

## 端の場合

- 不正な入力: `inkCleared` の値が数でない・知らない欄 → `repo` が落とし、規則が断る。`removeInk` の `now` が数でない → `TypeError`。
- 重複と境界: サーバーの時刻と `editedAt` が**同じ**ときは、サーバーを残す（保存しない）。空の手書きどうし（こちらも空・サーバーも消してある）でも、同じ決まり。消したあとに新しく書くと、`inkCleared` は消える。`superseded` のあとすぐに書いた線は、消えずに保存される。
- 違反や失敗の見せ方: 新しいほうに入れかえたことは、欄の下の知らせで見せる（黙って入れかえない）。確かめのための読みこみ（`getRecord`）に失敗したら、保存の失敗として、今ある「保存できませんでした」とやり直しに乗せる。

## 守ること

- `git add`・`git commit` はしない。上に書いたことのほかは変えない。文字の記録・添付・重要用語の動きは変えない。
- 代役で、「端末 A で保存に失敗 → 端末 B が保存 → A でやり直し」で B の中身が残ること、「B が全部消す → A の古い下書き」で生き返らないことを確かめ、報告に書く。
