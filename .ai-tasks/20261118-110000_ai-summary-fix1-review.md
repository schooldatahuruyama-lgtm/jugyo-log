## 1. 「名前や ID は送りません」が、実際と合っていない（指摘 1）

名前・ID の**欄**は送っていないが、生徒が**文の中に**書いた名前などは、そのまま送られる。画面の文が、実際より強い約束になっている。文の中身から名前を確実に取りのぞくことは、できない。次の 2 つを行う。

- **文を正しくする。** 次の 2 か所を、このとおりに変える。
  - カードの説明: 「文字で書いた記録を OpenAI に送り、AI がまとめます。名前や ID の欄は送りません。手書きは入りません。」
  - 確かめの窓の文: 「この授業の、文字で書いた記録（N 人分）を、OpenAI に送ります。名前や ID の欄は送りません。**生徒が文の中に書いた名前などは、そのまま送られます。**」（60 人を超えるときの文は、今のまま後ろに付く）
- **決まった形のものは、送る前に伏せる。** `js/ai-summary-logic.js` に `maskText(text) → 文字` を足し、`buildSummaryRequest` が `learned`・`question`・`memo` に通す。伏せるもの:
  - 生徒の ID の形（`s` ＋数字 2 けた ＋ `-` ＋数字 3 けた。大文字・全角もふくむ）→ `（ID）`
  - メールアドレスの形 → `（メール）`
  - 数字が 10 けた以上続くもの（間に `-`・空白が入ってもよい。電話番号など）→ `（番号）`
  - 伏せたあとの文字で、長さの上限（2000）を数える。
- README の「AI のまとめ」の節に、同じ説明（欄は送らない・文の中の名前はそのまま送られる・上の 3 つは伏せる）を書く。

## 2. 保存したまとめが、別の生徒へつながる（指摘 2）

今は、開き直すと、まとめを作ったときの「呼び名 → 生徒」の対応が無く、今の出席番号・並び順で引き直している。作ったあとに番号を付けかえた・名簿にいない生徒の数が変わったとき、別の生徒の記録が開く。

- まとめを保存するとき、`aiSummaries/<クラス>/<授業>` に、**作ったときの対応 `labels: { 呼び名: 生徒 ID }`** を一緒に保存する（先生だけが読める場所。規則は変えない。今の規則は、ほかの子を止めていない）。OpenAI には、今までどおり送らない。
- 開いたとき、呼び名のボタンは、**保存してある `labels` から生徒を引く**。引いた生徒が、今の対象の生徒（一覧にいる生徒）にいれば、ボタンにする。いなければ、文字だけ。
- `labels` が保存されていない古いまとめ・`labels` の形がおかしいまとめは、**呼び名を全部、文字だけ**にする（今の番号で引き直さない）。
- `repo.setAiSummary`・`repo.getAiSummary`・`cleanAiSummary`（データベースから読むとき）を合わせる。`labels` の値は、生徒の ID の形（今ある ID の確かめ）でなければ落とす。

## 3. GAS への接続を 2 つ作っている（指摘 4）

`js/views/teacher-review.js` が、自分で `createGas` している。`js/main.js` の接続と二重になる。

- `js/main.js` で作っている `gas` を使い、`ctx.ai = { summarize(request) }`（中で `requestAiSummary({ gas, request })`）として画面に渡す。練習モードも、今ある練習用の GAS の代役から同じ形で渡す。
- `js/views/teacher-review.js` から、`createGas`・`gasEndpoint`・`GAS` の読みこみを外し、`ctx.ai.summarize` を使う。`ctx.ai` が無いとき（古い呼び出し・テスト）は、「AI でまとめる」を出さず、カードに「この画面では、AI のまとめを使えません。」と出す。
- AI の呼び出しは、今の GAS の順番待ち（1 つずつ送る）に並ぶ。まとめを作っている間に、同じ先生の画面でファイルの読みこみが待たされることがある。これは割り切る（先生 1 人・30 秒ほど）。`ctx.ai` を作る所のコメントに、1 行で書く。

## 端の場合

- 不正な入力: `maskText` に文字でないもの → `''`。伏せる形が文の端・続けて 2 つ・全角でも、伏せる。10 けた未満の数字（「340」「2026」「３４０ｍ」）は、伏せない。保存した `labels` に、呼び名の形でない名前・ID の形でない値がある → その組だけ落とす。
- 重複と境界: 数字ちょうど 10 けたは伏せる・9 けたは伏せない。`labels` の生徒が名簿から外れていても、記録か返事があって一覧にいれば、ボタンのまま。一覧にいなければ文字だけ。作り直すと、`labels` も新しいものに入れかわる。
- 違反や失敗の見せ方: 文は、上に書いたものだけ変える。失敗の文は今のまま。
