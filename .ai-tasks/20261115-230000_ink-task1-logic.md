## 設定（`js/config.js` に足す）

```js
  // 手書き: 紙の幅と 1 枚ぶんの高さ（座標の単位）、上限、保存の待ち時間
  ink: {
    width: 800, pageHeight: 400, maxPages: 10,
    maxStrokes: 2000, maxPoints: 2000, maxBytes: 250000,
    colors: ['#111111', '#C8402F', '#0B57B0'], widths: [3, 7],
    eraserRadius: 10, simplifyTolerance: 0.6, snapRatio: 0.0875, undoMax: 30,
    saveDelayMs: 3000, saveIntervalMs: 30000,
  },
```

## データの形

- 線（stroke）: `{ c: 0|1|2, w: 0|1, p: [x0, y0, x1, y1, …] }`。`c` は `CONFIG.ink.colors` の番号、`w` は `CONFIG.ink.widths` の番号。`p` は点を平らに並べた数の配列（2 点以上 = 4 個以上、偶数個、`maxPoints` 点まで）。x は 0〜`width`、y は 0〜`height`。小数 1 けたに丸める。
- 手書き（ink）: `{ v: 1, h: 400 の倍数（400〜4000）, s: [stroke, …] }`。
- 関数は、渡された配列・オブジェクトを書きかえない（新しいものを返す）。

## 関数（`js/ink-logic.js`。`CONFIG` を import して使う）

- `emptyInk() → ink`: `{ v: 1, h: 400, s: [] }`。
- `round1(n) → number`: 小数 1 けたに丸める。
- `cleanStroke(value, height) → stroke | null`: 形を確かめて、正しい stroke を返す。オブジェクトでない、`c`・`w` が番号の範囲外・整数でない、`p` が配列でない・奇数個・4 個未満・`maxPoints` 点をこえる・数でない値や有限でない値を含む → `null`。x・y が範囲の外の点は、範囲の中に切りつめる（0〜`width`、0〜`height`）。座標は `round1`。
- `cleanInk(value) → ink`: どんな値でも、正しい ink にして返す。オブジェクトでない・`v !== 1` → `emptyInk()`。`h` が 400 の倍数でない・範囲外 → 範囲に入るよう切り上げて直す（400 未満や数でないときは 400、4000 をこえるときは 4000）。`s` が配列でなければ空。`cleanStroke` で `null` になった線は落とす。`maxStrokes` 本をこえた分は落とす（先頭から残す）。
- `parseInk(text) → ink | null`: JSON の文字を読む。JSON として読めない・オブジェクトでない・`v !== 1` のときは **`null`**（こわれたファイルを、空の手書きとして扱わないため）。読めたら `cleanInk` を通して返す。
- `serializeInk(ink) → string`: `JSON.stringify(cleanInk(ink))`。
- `inkBytes(ink) → number`: `serializeInk` の UTF-8 のバイト数（中身は ASCII なので、文字数でよい）。
- `isEmptyInk(ink) → boolean`: 線が 1 本もない。
- `simplify(points, tolerance) → points`: 平らな配列の点を、Ramer–Douglas–Peucker の方法で間引く。はじめと終わりの点は残す。2 点以下はそのまま。同じ点が続くところは 1 つにする。再帰で深くなりすぎないよう、くり返し（スタック）で書く。
- `makeStroke({ points, color, width, ruler }, height) → stroke | null`: 書き終えた線を作る。`points` は平らな配列（画面から来た点。紙の座標に直してある）。
  - `ruler` が `true`: はじめの点と終わりの点の 2 点だけにし、`snapLine` を通す。
  - `ruler` が `false`: `simplify(points, CONFIG.ink.simplifyTolerance)`。それでも `maxPoints` 点をこえるときは、等しい間隔で点を抜いて `maxPoints` 点にする（はじめと終わりは残す）。
  - 点が 1 つだけ（軽くさわっただけ）のときは、同じ場所に 0.1 だけずらした 2 点目を足して、点として残す。点が無ければ `null`。
  - 最後に `cleanStroke` を通す。
- `snapLine(x0, y0, x1, y1) → [x0, y0, x1, y1]`: 定規の線。`|dy| < |dx| × snapRatio` なら `y1 = y0`（横にそろえる）。`|dx| < |dy| × snapRatio` なら `x1 = x0`（縦にそろえる）。それ以外はそのまま。
- `hitStroke(stroke, x, y, radius) → boolean`: 点 (x, y) が、線のどれかの線分から `radius + 線の太さ / 2` 以内にある（線分と点の距離）。
- `eraseAt(ink, x, y) → ink`: 当たった線（`CONFIG.ink.eraserRadius`）をすべて取り除いた ink。当たらなければ、**同じオブジェクト**を返す（変わっていないことが分かるように）。
- `addStroke(ink, stroke) → { ink, error }`: 線を足す。`maxStrokes` に達している → `{ ink（元のまま）, error: 'too-many' }`。足したあとの `inkBytes` が `maxBytes` をこえる → `{ ink（元のまま）, error: 'too-big' }`。足せたら `{ ink（新しい）, error: null }`。
- `addPage(ink) → { ink, error }`: `h` を `pageHeight` だけ増やす。`pageHeight × maxPages` に達している → `{ ink（元のまま）, error: 'too-long' }`。
- `canAddPage(ink) → boolean`。
- `strokePath(stroke) → string`: SVG の `d`（`M x0 y0 L x1 y1 …`。小数 1 けた）。
- `inkBounds(ink) → { x, y, w, h } | null`: すべての線を囲む四角（線の太さの半分をふくめる）。線が無ければ `null`。
- `createHistory(max) → { push(ink), undo(current) → ink | null, canUndo() }`: 「1 つ戻す」のための入れ物。`push` は、変える前の ink を積む（`max` をこえたら古いものから捨てる）。`undo` は、いちばん新しいものを取り出して返す（無ければ `null`）。

## 端の場合

- 不正な入力: 上に書いたとおり、`cleanStroke`・`cleanInk` が落とす・直す。`parseInk` は、こわれた JSON に `null` を返す。数の文字列（`'12'`）は数として扱わない（落とす）。`NaN`・`Infinity` は落とす。とても大きい座標は、範囲に切りつめる。
- 重複と境界: `maxStrokes` 本ちょうどまでは足せる（次が `'too-many'`）。`maxBytes` ちょうどまでは足せる。`maxPoints` 点ちょうどの線は通る。`h` が 4000 のとき `addPage` は `'too-long'`。同じ点だけの線は、点として残る。`simplify` は、まっすぐに並んだ点を 2 点にする。
- 違反や失敗の見せ方: このファイルは画面を持たない。上限は `error` の文字で呼び出し元に返し（黙って捨てない）、呼び出し元（Task 3・4）が文を出す。

## 追加するテスト（`tests/ink-logic.test.js`。今あるテストの書き方に合わせる）

上の関数ごとに、ふつうの場合と、「端の場合」に書いた場合を確かめる。少なくとも次を入れる。

- `cleanStroke`: 正しい線が通る。`c: 3`・`w: 2`・`c: 1.5`・`p` が奇数個・2 個・`'12'` をふくむ・`NaN` をふくむ → `null`。範囲の外の点は切りつめる。座標が小数 1 けたになる。
- `cleanInk`: `null`・`{ v: 2 }` → 空。`h: 450` → 800。`h: 99999` → 4000。おかしい線だけ落ちる。2001 本 → 2000 本。
- `parseInk`: `'{'` → `null`。`'[]'` → `null`。`'{"v":1,"h":400,"s":[]}'` → 空の ink。
- `serializeInk` → `parseInk` で、元と同じ中身に戻る。
- `simplify`: まっすぐな 10 点 → 2 点。角のある線は、角の点が残る。同じ点の連続 → 1 つ。10 万点でもスタックがあふれない。
- `makeStroke`: 定規なしで波の線 → 点が減り、はじめと終わりが同じ。定規あり → 2 点。定規ありで、ほぼ横（かたむき 3 度）→ y がそろう。かたむき 10 度 → そろわない。ほぼ縦も同じ。1 点 → 2 点の線。点なし → `null`。
- `hitStroke`・`eraseAt`: 線の上・線の近く・遠く。当たらないときは同じオブジェクト。2 本に当たると 2 本消える。
- `addStroke`: 1999 本 → 足せる。2000 本 → `'too-many'`。バイト数の上限 → `'too-big'`（元の ink のまま）。
- `addPage`・`canAddPage`: 3600 → 4000 は足せる。4000 → `'too-long'`。
- `strokePath`・`inkBounds`: 決まった線での値。線なし → `null`。
- `createHistory`: 積んだ順の逆に戻る。`max` をこえると古いものが消える。空のとき `undo` は `null`。
