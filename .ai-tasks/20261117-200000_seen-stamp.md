# 実装指示書: 先生の「見ました」をスタンプにする

あなた（Codex）は、この指示書に沿ってコードを書きます。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

先生の要望（2026-11-17）: 先生が振り返りを見たとき、**生徒の振り返りに「見た」スタンプが押される**ようにしたい。スタンプは、理科アプリの先生のキャラクター（まる先生）を使う。

先生の決定:

- スタンプは、**先生がボタンを押したとき**に押される（記録を開いただけでは押されない）。
- スタンプの絵は、Claude Code が `assets/stamps/seen-a.svg`〜`seen-f.svg` の **6 枚**を用意した（400×400 の SVG。理科アプリの 6 人の先生: a まる先生・b しずく博士・c ぷにカプセル・d もくもく先生・e キューブ先生・f まめ博士。絵は先生が用意したもので、中身は変えていない）。**これらの絵は、この指示書では変えない。**
- **6 枚のうちどれが押されるかは、ランダム**（先生の決定）。ただし、同じスタンプは、いつ・だれが見ても同じ絵にする（開くたびに変わらない）。

### どの絵にするかの決め方

データの形を変えないために、絵は保存せず、**押した時刻から決める**。`js/reply-logic.js` に足す:

```js
// スタンプの絵（'a'〜'f'）を、生徒・授業・押した時刻から決める。同じ入力なら、いつも同じ絵。
export function stampKind({ studentId, lessonId, updatedAt }) → 'a' | 'b' | 'c' | 'd' | 'e' | 'f'
```

- `studentId + '/' + lessonId + '/' + updatedAt` の文字から、かんたんな数（FNV-1a などの、自前の 32 ビットのハッシュ）を作り、6 で割った余りで決める。`Math.random` は使わない。
- `updatedAt` が数でない・ID が文字でない → `'a'`。
- 押し直す（取り消してもう一度押す）と時刻が変わるので、絵が変わることがある。これでよい。
- 「全員にスタンプを押す」は全員同じ時刻になるが、生徒の ID がちがうので、生徒ごとに絵がばらける。
- 絵の道は `assets/stamps/seen-<kind>.svg`。先生の一覧・1 人の記録・生徒の授業ページは、同じ決め方を使い、**同じ生徒・同じ授業なら、先生にも生徒にも同じ絵が出る**。

データの形は変えない。今ある先生の返事（`replies/<クラス>/<授業>/<生徒>` の `seen: true`。`.ai-tasks/20261116-070000_reply-task1-data.md`）を、「スタンプが押してある」として使う。規則・GAS・中つぎは変えない。

## 画面の動き（Claude Code の設計。先生に伝えてある）

### 先生: 記録の一覧（`js/views/teacher-review.js`）

- 「全員分をコピー」の近くに、ボタン「**全員にスタンプを押す**」を足す。
  - 対象: その授業で、**振り返りを書いた生徒**（「分かったこと」か「疑問」に文字か手書きがある、または理解度を選んである）のうち、まだスタンプが押されていない生徒。
  - 押すと、確かめの窓: 題「スタンプを押しますか？」、文「振り返りを書いた N 人に、スタンプを押します。」、ボタン「押す」／「やめる」。
  - 対象が 0 人のときは、ボタンを押せないようにし、となりに「（押す相手がいません）」と出す。
  - 押している間は「スタンプを押しています…」、終わったら「N 人にスタンプを押しました。」（`role="status"`）。失敗したら「スタンプを押せませんでした。もう一度押してください。」（`role="alert"`）。一部だけ成功することは無い（1 回の update で全員分を書く）。
  - すでに返事の文がある生徒は、文を残したまま `seen: true` を足す。
- 行の印: スタンプが押してある生徒は、今の「✓ 見ました」の代わりに、小さいスタンプの絵（24px。`alt=""`）と「スタンプ」を出す。文もあるときは「💬 返事ずみ」とスタンプの両方。
- 返事の読みこみに失敗しているとき（今ある「返事の印を読みこめませんでした。」）は、「全員にスタンプを押す」は押せない（知らずに上書きしないため）。

### 先生: 1 人の記録（`js/views/parts/reply-box.js`・`js/views/teacher-record.js`）

- 「先生から」の欄の、今あるチェック「見ました（文を書かずに、印だけ付けられます）」を、ボタンに変える。
  - まだ押していないとき: ボタン「スタンプを押す」。押すと、**すぐ保存する**（「保存する」を押さなくてよい。返事の文の書きかけがあっても、スタンプだけを保存し、書きかけの文は入力欄に残す。保存してある文は変えない）。
  - 押してあるとき: スタンプの絵（56px）と「スタンプを押してあります」、ボタン「スタンプを取り消す」（確かめなしで、すぐ取り消す。文が無い返事なら、返事そのものを消す。文があるなら `seen` だけ外す）。
  - 状態の文: 「スタンプを押しました（生徒に見えています）」「スタンプを取り消しました」。失敗は、今ある「保存できませんでした。もう一度押してください。」。
- 返事の文の「保存する」「返事を取り消す」は、今のまま（文を保存しても、スタンプの有無は変えない）。
- 記録がまだ無い生徒でも、スタンプは押せる（今の返事と同じ）。

### 生徒: 授業ページ（`js/views/student-lesson.js`）

- スタンプが押してあるとき、「**振り返り**」の区切り（緑の帯の区切り）の右上に、スタンプの絵（**小さめ**。幅 64px。縦向きの狭い画面では 56px。先生の要望で、目立ちすぎない大きさにする）を、紙に押したように少し重ねて出す。`alt="先生が見ました"`。振り返りの入力欄・ボタンに重ならないこと（押せなくならないこと）。
- はじめて出るときに、1 回だけ、ぽんと押される動き（0.3 秒。大きめ→ふつうの大きさ）。`prefers-reduced-motion: reduce` のときは、動かさない。
- 今ある「先生から」の箱: 返事の文があるときだけ出す。スタンプだけのときは、箱を出さない（今の「✓ 先生が見ました」の文は、スタンプに置きかえる）。文とスタンプの両方があるときは、箱（文と日付）とスタンプの両方。
- スタンプの絵が読みこめなかったときは、同じ場所に「✓ 先生が見ました」の文を出す。

### 生徒: 授業の一覧（`js/views/student-home.js`・`js/views/parts/lesson-tile.js`）

- 今は、返事があると「💬 先生から」の印。これを分ける: 文がある →「💬 先生から」（今のまま）。スタンプだけ → 小さいスタンプの絵（20px）と「見ました」。
- 一覧は `replyMarks`（時刻だけ）しか読んでいないので、文かスタンプかが分からない。**一覧では分けず、今の「💬 先生から」のままでよい**（新しい通信を足さない）。ただし文字は「先生から」に合うように、スタンプだけのときも不自然でない今の文のままにする。＝ **一覧は変えない。**

### 見た目（`css/app.css`）

スタンプは、今ある色・角丸に合わせ、影を付けない（絵の中に付いている）。ボタンは 44px 以上。

## 読み書き（`js/repo.js`・`js/reply-logic.js`）

- `repo.stampReplies(classId, lessonId, studentIds, existing, now)`: `studentIds`（配列）の全員に、`replies/…/<生徒>` を `{ text（existing にあれば）, seen: true, updatedAt: now }`、`replyMarks/<生徒>/…` を `now` にする書きこみを、**1 回のルート update** で行う。`existing` は `listReplies` の結果（文を残すため）。`studentIds` が配列でない・空・ID の形でないものが入っている → `TypeError`。上限は 60 人（超えたら `TypeError`）。
- `reply-logic` に、対象の生徒を決める関数を足す: `stampTargets({ students, records, replies }) → 生徒 ID の配列`（振り返りを書いていて、`replies[id]?.seen` が無い生徒。並びは `students` の順）。「振り返りを書いた」の決まりは、上の「対象」のとおり。DOM を使わない。
- 1 人のスタンプ（押す・取り消す）は、今ある `setReply`・`removeReply` を使う。

## 端の場合

- 不正な入力: `stampReplies` に空の配列・60 人より多い配列・`null` → `TypeError`（画面は、0 人のときボタンを押せない。60 人を超えるクラスでは、「一度に押せるのは 60 人までです。」と出して止める）。`existing` の文が 400 文字を超えている・文字でない → その生徒の文は入れず、`seen` だけにする。記録の欄が文字でない → 書いていないものとして扱う。
- 重複と境界: もう全員に押してあるとき → 0 人（ボタンを押せない）。「全員にスタンプを押す」を続けて 2 回押しても、1 回だけ送る。確かめの窓を開いている間に、別の端末で押された分は、そのまま上書きしてよい（`seen: true` のまま）。1 人の記録で押した直後に一覧へ戻ると、印が出ている。スタンプを取り消したあと、もう一度押せる。名簿にいない生徒も、振り返りを書いていれば対象。
- 違反や失敗の見せ方: 上に書いた文を、ボタンのそばに出す。通信の失敗で、書きかけの返事の文を消さない。生徒の画面では、スタンプの失敗が記録の保存の状態を変えない。
