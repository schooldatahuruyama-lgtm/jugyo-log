# 実装指示書: 確認用のダミーのデータ（1 か月分の授業・板書の画像・生徒の記録）を作る道具

あなた（Codex）は、この指示書に沿ってコードとデータを書きます。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

先生の指示（2026-11-17）: 今ある確認用の生徒（確認用のクラスの 1〜3 番）に、**1 か月使ったつもりの記録**を入れて、先生の「記録」や「まとめ」を確かめたい。**板書は、黒板に書いたような画像を Codex に作らせる。**

この指示書で作るのは、**データの中身**と、**板書の画像を描く道具**だけ。アプリに入れる作業（先生として授業と板書を足す、生徒として記録を書く）は、Claude Code と先生が、ブラウザで行う。アプリ本体・規則・GAS は変えない。

## 作るもの

置き場所は `tools/dummy/`（公開用のブランチには入らない。`tools/pages-branch.ps1` は変えない）。

### 1. `tools/dummy/month.json` — 1 か月分の中身

中学 1 年の理科（光・音・力）。本物の教科書の文を写さず、自分の言葉で書く。人の名前・学校名・本当の出来事は入れない。

```json
{
  "units": [{ "key": "light-sound", "name": "光と音" }, { "key": "force", "name": "力" }],
  "lessons": [
    {
      "date": "2026-10-19",
      "title": "光の進み方",
      "unit": "light-sound",
      "terms": ["光源", "光の直進"],
      "board": { "title": "…", "aim": "…", "blocks": [ … ], "summary": "…" },
      "records": {
        "1": { "memo": "…", "learned": "…", "question": "…", "level": 4 },
        "2": { "memo": "…", "learned": "…", "question": "…", "level": 2 },
        "3": null
      }
    }
  ]
}
```

- 授業は、次の 13 回（日付・授業名・単元は、このとおり）:

  | 日付 | 授業名 | 単元 |
  |---|---|---|
  | 2026-10-19 | 光の進み方 | 光と音 |
  | 2026-10-21 | 光の反射 | 光と音 |
  | 2026-10-23 | 鏡にうつる像 | 光と音 |
  | 2026-10-26 | 光の屈折 | 光と音 |
  | 2026-10-28 | 凸レンズのはたらき | 光と音 |
  | 2026-10-30 | 凸レンズと像 | 光と音 |
  | 2026-11-02 | 音の伝わり方 | 光と音 |
  | 2026-11-04 | 音の速さ | 光と音 |
  | 2026-11-06 | 音の大きさと高さ | 光と音 |
  | 2026-11-09 | 力のはたらき | 力 |
  | 2026-11-11 | 力の表し方 | 力 |
  | 2026-11-13 | 重さと質量 | 力 |
  | 2026-11-16 | 力のつり合い | 力 |

- `terms`: 授業ごとに 2〜4 個。1 個は 1〜20 文字（アプリの上限）。
- `board`: 板書の中身。`title`（授業名）、`aim`（めあて。1 文）、`blocks`（2〜3 個。それぞれ `{ "heading": "…", "lines": ["…", …], "figure": "<下の図の名前> または null" }`。1 行は全角 22 文字まで、1 つの block は 6 行まで）、`summary`（まとめ。1〜2 文）。
- `figure` に使える名前（画像の道具が描く、かんたんな図）: `reflection`（鏡と入射光・反射光・角）、`refraction`（空気と水の境目と光）、`lens`（凸レンズと焦点・光の道）、`wave`（音の波。振幅と振動数）、`force-arrow`（物体と力の矢印・作用点）、`balance`（つり合う 2 つの力）。合う授業にだけ使う。
- `records`: 生徒の番号（`"1"`・`"2"`・`"3"`）ごとに、`memo`（授業中のメモ。1〜4 行）、`learned`（分かったこと）、`question`（疑問。無い日は `""`）、`level`（1〜4 の整数。アプリの理解度。**どちらが「よく分かった」かは、`js/` の今の決まりを読んで合わせ、`month.json` の先頭近くに `"levelNote"` として 1 行書く**）。書いていない日は `null`。
  - 3 人の様子を変える: 1 番 … ほぼ毎回書く。よく分かっている。疑問は発展的。2 番 … 書く日が多いが、理解度が低い日が 4〜5 回ある。疑問が具体的（つまずき）。3 番 … 13 回のうち 4 回は書いていない（`null`）。短い文が多い。理解度はまちまち。
  - 中学 1 年生が書きそうな、やさしい言葉・短い文にする。まちがった理解をしている文が、2 番と 3 番に合わせて 3〜4 個あってよい（先生が気づけるかを見るため）。
  - 同じ授業で、2 人以上が同じ言葉（重要用語や「レンズ」「振動」など）でつまずいている日を、3 回は作る（「まとめ（自動）」で見えるように）。
  - 文字の上限: `memo`・`learned`・`question` は、それぞれ 2000 文字まで（アプリの上限）。ふつうは 20〜120 文字。

### 2. `tools/dummy/boards.js` — 板書の画像を描く道具

ブラウザの中で動く、1 つのファイル（`import`・`export` を使わない。ほかのファイルを読みこまない。ネットワークを使わない）。読みこむと、次の 1 つの関数ができる。

```js
// 1 回分の板書を描いて、JPEG の Blob を返す。
globalThis.drawDummyBoard(board, { width = 1600, height = 900, quality = 0.85 } = {}) → Promise<Blob>
```

- 見た目: 緑の黒板（少しむらのある深い緑）、木の枠、下にチョーク受け。字は、チョークで書いたように少しかすれた白・黄・ピンク・水色。上に授業名、その下に「めあて」（黄色の線で囲む）、まん中に `blocks` を横に並べる（2 個なら 2 列、3 個なら 3 列。見出しは黄色）、下に「まとめ」（ピンクの線で囲む）。
- 字の書体は、端末にあるものを使う（例: `'UD デジタル 教科書体 NK-R', 'Hiragino Maru Gothic ProN', 'Yu Gothic', sans-serif`）。外の書体を読みこまない。
- かすれ: 字を描いたあと、細かい点を緑で散らすなどして、チョークらしくする。毎回同じ絵になるよう、乱数は**種つきの自前の乱数**を使う（`Math.random` を使わない。種は `board.title` から作る）。
- 図（`figure`）: 上の 6 つを、線と弧と矢印で、かんたんに描く（色つきのチョークで。角や力の名前の短いラベルを付ける）。`null`・知らない名前は、描かない。
- 字が枠からはみ出さないこと: 行が長いときは、その block の字を小さくする（下限 22px）。それでも入らない行は、枠の幅で折り返す。
- 返す Blob は `image/jpeg`。

### 3. `tools/dummy/preview.html` — 目で確かめるページ

`boards.js` と `month.json` を読み、13 枚の板書を縦に並べて見せる（1 枚ずつ、日付・授業名・画像の大きさ（KB）を添える）。手元のサーバー（`http://127.0.0.1:8791/tools/dummy/preview.html`）で開く前提。アプリの CSS・JS は使わない。

何のための道具か、中身、アプリへの入れ方は Claude Code と先生がブラウザで行うこと、公開用のブランチに入らないこと、を短く書く。

## 端の場合

- 不正な入力（`drawDummyBoard`）: `board` が物でない → `TypeError`。`blocks` が配列でない・空 → 見出しとめあてとまとめだけ描く。文字でない行は飛ばす。`width`・`height` が正の数でない → `TypeError`。とても長い 1 行（200 文字）→ 折り返して、枠の中に収める（あふれた分は、その block の下で切る）。
- 重複と境界: 同じ `board` を 2 回描くと、同じ大きさ・同じ絵（種つきの乱数）。block が 1 個・4 個以上でも、列を等分して描く。
- 違反や失敗の見せ方: `preview.html` は、読みこみや描くのに失敗した回を、赤い字で「描けませんでした: 理由」と出し、ほかの回は続ける。

## テスト

- `tests/dummy-month.test.js`（新しい）: `month.json` が上の形どおり（13 回、日付と授業名と単元が表のとおり、`terms` の数と長さ、`board` の形と行の長さ・数、`figure` の名前、`records` の番号・`level` の範囲・文字の長さ、3 番の `null` が 4 回、同じ日付が無い）。人の名前らしい文字（「さん」「くん」「先生の名前」など）は調べなくてよい。
- `boards.js` は canvas が要るので、自動テストは「ファイルを読むと `drawDummyBoard` が関数になる」「不正な引数で `TypeError`」まででよい（canvas の代役が要るなら、かんたんなものを作る）。絵は、Claude Code がブラウザで見て確かめる。
- `npm test` がすべて成功し、`node --check tools/dummy/boards.js` が通る。
