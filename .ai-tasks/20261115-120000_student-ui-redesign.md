# 実装指示書: 生徒の画面を、先生が出した見本の画像の見た目に直す（番号・記入済みの印・資料をめくる・まだの知らせ）

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

先生（ユーザー）が、生徒の画面の見本の画像を出し、「画像のような UI に直してください」と頼んだ（2026-11-15）。画像は `docs/design/2026-11-15-student-ui.png` にある（画像を読めない場合は、下の文のとおりに作ればよい）。あわせて、先生が選んだ 4 つの工夫を入れる:

- B: 枠の見出しに番号を付ける
- C: 振り返りを書けたら、見出しに印を出す
- E: 先生の資料を、1 枚ずつ横にめくる形にする
- F: 一覧で、振り返りがまだの授業を知らせる

（要件定義書 `docs/requirements.md` の「UI/UX 方針」。設計書 7.2・7.3 の、置くもの・順番・動きは変えない。変えるのは見た目と、上の 4 つ。）

## 変える・作るファイル

- 変える: `css/base.css`、`css/app.css`、`js/views/student-lesson.js`、`js/views/student-home.js`、`js/views/parts/lesson-tile.js`、`js/views/parts/material-pane.js`、`js/views/teacher-record.js`、`js/student-list-logic.js`、`tests/student-list-logic.test.js`
- ほかのファイルは変えない（先生のほかの画面・ログイン・接続確認ページの見た目は、今回は変えない。`css/base.css` の今ある変数の値を変えると、ほかの画面にも効くので、**変えてよい変数は下に書いたものだけ**）。

## 1. 色と形（`css/base.css` と `css/app.css`）

`css/base.css` の `:root` で、次の変数を直す・足す（値は、白い文字・濃い文字とのコントラストが 4.5:1 以上になるものを選んである。変える必要があると思ったら、変えずに報告に書く）:

| 変数 | 値 | 使う所 |
|---|---|---|
| `--teacher` | `#0B57B0` | ① の番号の丸・見出しの文字 |
| `--teacher-bg` | `#F1F7FE` | ① の本体の背景 |
| `--teacher-band` | `#D6E8FB` | ① の上の帯 |
| `--mine` | `#9A4A08` | ② の番号の丸・見出しの文字（黄土色から、オレンジ寄りの茶色に変える） |
| `--mine-bg` | `#FDF4EA` | ② の本体の背景 |
| `--mine-band` | `#FBE3CC` | ② の上の帯 |
| `--reflect` | `#14694B` | ③ の番号の丸・見出しの文字・選んだ理解度・「記入済み」の印 |
| `--reflect-bg` | `#EEF7F1` | ③ の本体の背景 |
| `--reflect-band` | `#D5EBDD` | ③ の上の帯 |
| `--page-warm` | `#FAF7F2` | 生徒の授業ページ・一覧の、ページの背景 |
| `--soft-line` | `#C9CFDD` | 入力欄・つながったボタン・白いボタンの細い線 |
| `--soft-shadow` | `0 2px 6px rgba(31, 42, 107, 0.12)` | 枠・ボタン・タイルの影 |

形（生徒の授業ページ・授業の一覧・先生が見る 1 人の記録に使う）:

- ページの背景は `--page-warm`。その上に、白い大きな入れ物（角の丸み 16px、`--soft-shadow`）を置き、中に上部の帯と 3 つの枠を入れる。
- **3 つの枠は、太い色の枠線をやめる。** 角の丸み 14px、`--soft-shadow`、線は付けないか、ごく細い線（1px、帯の色）。枠の上に**色の帯**（`--…-band`）があり、その中に、番号の丸（直径 34px、枠の色で塗り、白い太い数字）・見出し（太い文字 22px、枠の色）・その下に小さい説明（15px）。帯の下が本体（`--…-bg`）。
- 入力欄（`textarea`）: 白い背景、1px の `--soft-line`、角の丸み 10px。フォーカスのときは、枠の色の 2px の線。
- 白いボタン（「‹ 一覧へ」「＋ 写真・PDF」「‹」「›」「まだの授業だけ見る」）: 白い背景、1px の `--soft-line`、角の丸み 12px、`--soft-shadow`、太い文字。高さ 44px 以上。
- 保存の状態（「✓ 保存しました」など）は、今の `statusChip` のまま、上部の帯の右に出す。
- つながった理解度のボタン: 外側は 1px の `--soft-line` と角の丸み 10px、ボタンの間は 1px の `--soft-line`。選んだものは `--reflect` で塗り、白い太い文字と「✓」。高さ 48px 以上。幅がせまいときは 2 列 × 2 段（今のまま）。
- 色だけで分けない: 番号・見出しの文字・説明で分ける。

## 2. 生徒の授業ページ（`js/views/student-lesson.js`）

- 上部: 白い入れ物の中の最初の行に、「‹ 一覧へ」、日付（小さく）と授業名（太く大きく）、右に保存の状態。
- 3 つの枠の見出しと説明（B）:
  - ① 「先生の資料」— 「資料をめくったり、拡大したりできます。」
  - ② 「自分の記録」— 「授業中に気づいたことを書きます。」
  - ③ 「振り返り」— 「授業の終わりに書きます。」
  - 番号の丸は飾り（`aria-hidden="true"`）。見出し `<h2>` の文字は「先生の資料」「自分の記録」「振り返り」のまま（番号を文字に入れない）。
- ③ の帯の右に、印を出す（C）: 理解度を選んでいないときは `！ 未記入`（黄色の線と背景の丸い印）、選んであるときは `✓ 記入済み`（`--reflect` より 1 段濃い緑 `#0F5239` で塗った丸い印、白い太い文字）。理解度を選んだ・読み直しで変わった、のたびに書きかえる。`role="status"` にする。保存の成否とは関係なく、今の画面の理解度で決める。
- 並べ方は今のまま（上の段に ① と ②、下の段いっぱいに ③。縦向きは 1 列）。入力・保存・添付・離れるときの確かめの動きは、何も変えない。

## 3. 先生の資料を 1 枚ずつめくる（E。`js/views/parts/material-pane.js`）

今は、資料をたてに全部並べている。これを、**1 枚ずつ出して、めくる形**にする。`materialPane({ ctx, classId, lessonId, lesson }) → { node, destroy() }` の形は変えない（生徒の授業ページと、先生が見る 1 人の記録の両方で使っている）。

- 出すのは 1 つの資料だけ。枠（4:3。黒っぽい背景ではなく、白い背景に、画像を縦横の比を保って収める）に、写真は小さい画像 → 本物の写真（今の入れかえの流れのまま）、PDF は 1 ページ目の小さい画像（無ければ「PDF」の文字）と名前。
- 枠の下の左に種類（「板書」「配布資料」）と名前、右に「1 / 3」。
- その下に、「‹」（`aria-label`「前の資料」）・点（今の位置の点は、形も変える）・「›」（`aria-label`「次の資料」）。はしでは押せない。**資料が 1 つだけのときは、ボタンと点と「1 / 1」を出さない。**
- 枠の上で指を横にすべらせると、めくれる。軽く押すと、今までどおり大きく表示する（`openViewer`）。動きの判定は、今ある `swipeDecision`・`stepIndex`（`js/student-list-logic.js`）と `CONFIG.swipe` を使う（`'tap'` で開く、`'prev'`・`'next'` でめくる、`'none'` は何もしない）。枠には `touch-action: pan-y`。枠は `<button>`（または `role="button"` と `tabindex`）にして、Enter・Space でも開ける。読み上げの名前は「板書 板書 を開く（1 / 3）」のようにする。
- 左右の矢印キーでもめくれる（枠かボタンにフォーカスがあるとき）。
- 本物の写真の読みこみは、今までどおり、開いたときに全部の写真を 1 回の `ctx.files.loadImages` で読む（めくるたびに通信しない）。読めなかった資料は、その資料を出しているときに「読みこめませんでした」と「もう一度」を出す（今の文のまま。小さい画像が出ていれば残す）。
- 資料が 0 個のときは「先生の資料は、まだありません。」（今のまま）。
- `destroy()` で、待ち受け・Blob の URL・開いているビューアーを片付ける（今のまま）。

## 4. 授業の一覧（F。`js/views/student-home.js`・`js/views/parts/lesson-tile.js`・`js/student-list-logic.js`）

- `js/student-list-logic.js` に足す: `todoLessons(lessons, marks, todayMs) → lesson[]`。`lessons` のうち、**日付が正しい形で、今日以前**で、`marks[lesson.id]` が 1〜4 の整数でないもの（振り返りがまだ）。順は `lessons` のまま。`marks` が `null`（印を読めなかった）のときは `[]`。
- 一覧の上（年度・並べ方の選択の下）に、`todoLessons` が 1 つ以上あるときだけ、黄色の帯を出す: 「振り返りがまだの授業が **N つ**あります。」と、右にボタン「まだの授業だけ見る」（`aria-pressed`）。押すと、一覧が、まだの授業だけになる（日付順・単元別の見出しはそのまま。授業が無くなった見出しは出さない）。ボタンの文は「全部の授業を見る」に変わり、もう一度押すと全部に戻る。0 になったら帯を出さず、しぼりこみも外す。クラスを切りかえたら、しぼりこみを外す。
- タイル（`lesson-tile.js`）の見た目: 白い入れ物、角の丸み 12px、`--soft-shadow`、線なし。上にサムネイル、下に日付（小さく）・授業名（太く）・印。**タイルの中の「先生の資料」「自分の記録」の小さな文字は外す。** 印（「✓ 記録あり」「！ 振り返りがまだ」「■ まだ保存できていません」）は残す。サムネイルの切りかえ（矢印・点・すべらせる）は今のまま。
- 一覧の上部: 白い入れ物の中に「授業ログ」（太く）・クラス名・出席番号、右にメニュー（今のボタンのまま）。ページの背景は `--page-warm`。

## 5. 先生が見る 1 人の記録（`js/views/teacher-record.js`）

- 同じ枠の形（上に色の帯・下に本体・影）にする。見出しは今のまま（「先生の資料」「この生徒の記録」「振り返り」）。**番号は付けない**（生徒のやることの順番なので）。説明の小さい文も付けない。
- 「振り返り」の帯の右に、同じ印（`✓ 記入済み` / `！ 未記入`）を出す。
- 上部の先生のメニュー（紺色の帯）は変えない。読み取り専用のまま。

## 端の場合

- 不正な入力: `todoLessons` は、`lessons` が配列でない・`marks` がオブジェクトでない・日付の形がおかしい授業・`todayMs` が数でない、でも落ちない（数えない）。形のおかしい資料は、今までどおり `materialList` が落とす。
- 重複と境界: 資料 1 個はめくる部品を出さない。最初の資料で「‹」、最後で「›」が押せない。すばやく続けて押しても、位置が範囲の外に出ない。今日の授業は「まだ」に数える・明日の授業は数えない。「まだ」が 0 になったら帯が消え、一覧は全部に戻る。しぼりこんだ結果が 0 件になることは無い（0 なら帯ごと消える）。横にはみ出さない（1180×820・820×1180）。ボタンは 44×44px 以上。
- 違反や失敗の見せ方: 読めない資料は、その資料の所に「読みこめませんでした」と「もう一度」。印を読めなかったとき（`marks` が `null`）は、今までどおり「一部を読みこめませんでした。」を出し、「まだの知らせ」の帯は出さない（まちがった数を出さない）。保存・添付の失敗の文は、今の場所のまま。

## 守ること

- `git add`・`git commit` はしない。
- 画面に出す文字は `textContent` で入れる。`innerHTML` を使わない。Blob の URL は使い終わったら外す。
- 生徒の本名などは出さない（今のまま、クラス名と出席番号だけ）。
- データベースの形・規則・GAS は変えない。入力・保存・添付の動きは変えない。
- 指示書に無い見た目の変更（先生のほかの画面など）はしない。必要だと思ったら、変えずに報告に書く。
