## 目的

レビューの指摘 2 件（High 1・Medium 1）に対応する。あわせて、Claude Code のブラウザでの確認で見つけた表示を 1 つ直す。

## 変える内容

### 指摘 1（High）: 画面の移動をやめたあと、リンクの欄が止まったままになる（`js/views/teacher-lesson.js`）

- `okToLeave()` の `finally` で、`termLocked = false` のあとに `syncTermControls()` ではなく `syncControls()` を呼ぶ（`syncControls()` は中で `syncTermControls()` も呼ぶ）。`okToLeave()` の最初の `termLocked = true` のあとも、同じく `syncControls()` にする。
- ほかにも、`termLocked`・`termBusy`・`linkBusy` を変えたあとに `syncTermControls()` だけを呼んでいる所があれば、`syncControls()` にそろえる（リンクの欄と用語の欄の止まり方が、いつも今の状態と合うように）。

### 指摘 2（Medium）: `closeAllDialogs()` で動画も閉じる（`js/ui.js`・`js/views/parts/video-player.js`）

- `js/ui.js` に足す:

  ```js
  // 確認ダイアログ以外の開いている窓（動画など）を、closeAllDialogs で閉じられるように登録する。戻り値は登録を外す関数
  export function registerDialog(close) { … }
  ```

  - `openDialogs` に `{ finish: () => close() }` の形で入れ、戻り値の関数で外す。`close` が関数でなければ何もせず、何もしない関数を返す。
  - `closeAllDialogs()` の中身は今のままでよい（`entry.finish(false)` を呼ぶ）。コメントを「開いている確認ダイアログと、登録された窓を…」に直す。
- `js/views/parts/video-player.js`: 開くときに `registerDialog(close)` で登録し、`close()` の中で登録を外す。
- `confirmDialog` の動きは変えない。

### 表示: 名前の無い動画（`js/link-logic.js`）

- 今は、名前を空にして足した YouTube の動画が、生徒の画面で「▶ youtu.be」「▶ youtube.com」と出る。分かりにくいので、`linkLabel(link)` を次にする:
  - `title`（空白を取って空でない）があれば、それ。
  - 無くて、`embedUrl(link.url)` が `null` でなければ「YouTube の動画」。
  - それ以外は、今までどおり `linkHost(link.url)`。

## 端の場合

- 不正な入力: `registerDialog` に関数でないものを渡す → 登録しない（投げない）。`linkLabel` に `null`・`url` の無いもの → 今までどおり `''`。
- 重複と境界: 動画を閉じたあとに `closeAllDialogs()` を呼んでも、2 回閉じない（何も起きない）。`closeAllDialogs()` のあとに、動画の `close()` を呼んでも壊れない。確認ダイアログと動画が同時に開いていても、両方閉じる。
- 違反や失敗の見せ方: 変えない（今の文のまま）。
