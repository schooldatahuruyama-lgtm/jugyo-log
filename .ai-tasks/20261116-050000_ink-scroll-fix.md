# 実装指示書: 書こうとすると画面が動いて書けない（iPad）の修正

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

先生の報告（2026-11-15。iPad の Safari の録画つき）: 写真（先生の資料の板書）を大きく開き、「✎ 書きこむ」→「書く」で書こうとすると、**画面が動いてしまって書けない**。

録画から分かったこと（Claude Code の調べ）:

- 書き始めた瞬間、道具のボタンが灰色になる（`pointerdown` が届き、線が始まっている）。
- 約 0.1 秒後、ボタンが元にもどり、表示の右にスクロールの棒が出て、写真が上下に動く（ブラウザがスクロールを始め、`pointercancel` で線が取り消されている）。
- この写真は、表示の枠（`.viewer-viewport`）より少し縦に長く、スクロールできる状態だった。

原因の見立て: 「書く」のとき、スクロールを止める手段が、紙（SVG）の `touch-action: none`（`js/views/parts/ink-pad.js` の `syncControls`）だけになっている。iPad の Safari では、これが効かない場面がある（SVG の要素に付けた `touch-action`）。ペンのときだけは `touchstart` の `preventDefault` があるが、指のとき・ペンと見分けられなかったときは、何も止めていない。

## 直すこと（`js/views/parts/ink-pad.js`・`css/app.css`）

`touch-action` だけに頼らず、**書ける状態のときは、紙の上の触れた動きで、ブラウザがスクロール・拡大を始めないようにする**。欄の手書き・写真・PDF のページの 3 つに同じく効く（同じ部品）。

1. 紙（`paper`）の `touchstart` と `touchmove`（どちらも `{ passive: false }`）で、次のどれかに当たるとき `preventDefault()` する。当たらないときは何もしない（今のスクロールのまま）。
   - 書ける（`canEdit()`）、かつ「書く」（`mode === 'write'`）
   - 書ける、かつ、触れたものの中にペンがある（今ある `touchType === 'stylus'` の見分け）
   - 線を書いている途中（`active` がある）
   - ペンで書いている途中、または離して 500 ミリ秒以内（今ある `penPointer !== null || Date.now() < penUntil`）。手のひらで画面が動かないようにする
   - `ev.cancelable` が `false` のときは呼ばない
2. 「書く」で書けるとき、紙に class `ink-paper-writing` を付ける（それ以外では外す。`syncControls` の中。今ある `ink-writing` と同じ条件）。
3. `css/app.css`: 
   - `.ink-paper.ink-paper-writing { touch-action: none; }`
   - `.picture-ink-overlay:has(.ink-paper-writing) { touch-action: none; }`（SVG ではなく、外側の HTML の要素でも止める）
   - 今ある `paper.style.touchAction` の入れ方は変えない。
4. 「動かす」のときの指の動き（欄の手書き: 上下のスクロール。写真・PDF: 上下左右と、2 本指の拡大）は、今のまま。ロック中・読みこみ中・先生の見るだけの表示も、今のまま（止めない）。

## 端の場合

- 不正な入力: `changedTouches`・`touchType` が無い端末（古いブラウザ・テストの代役）でも、例外を出さない。`touchmove` が来ない端末（マウス・PC）では、何も変わらない。
- 重複と境界: 2 本の指で触れたとき、「書く」では拡大・スクロールは始まらない（1 本目だけが線になる。今のまま）。「書く」→「動かす」に切りかえた直後から、指でスクロールできる。書けない状態（ロック・確かめの窓が開いている）では、「書く」でも止めない。ペンを離して 500 ミリ秒を過ぎたら、「動かす」では指でスクロールできる。
- 違反や失敗の見せ方: 画面に出す文は足さない。今ある「いま: 書く（指でもペンでも書けます）」のまま。

## テスト

- `tests/picture-ink-screen.test.js`・`tests/pdf-ink-screen.test.js`、または欄の手書きの画面のテスト（今ある所に合わせる）:
  - 「書く」で書けるとき、紙に `touchstart`・`touchmove`（`cancelable: true`）を送ると `defaultPrevented` になる。指（`touchType` なし・`'direct'`）でもなる。
  - 「動かす」で指 → ならない。「動かす」でペン（`'stylus'`）→ なる。
  - ロック中の「書く」→ ならない。
  - 線を書いている途中の `touchmove` → なる。
  - 「書く」で `ink-paper-writing` が付き、「動かす」・ロック中は付かない。
- `npm test` がすべて成功し、変えた `.js` は `node --check` が通る。

## 守ること

- `git add`・`git commit` はしない。変えるのは `js/views/parts/ink-pad.js`・`css/app.css`・テスト（と、テストの代役に足りない所があればその代役）だけ。
- 線の保存・下書き・道具の動きは変えない。ネットワークからパッケージを足さない。
