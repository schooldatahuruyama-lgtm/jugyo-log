# 実装指示書: 授業に「動画・サイトのリンク」を付ける

あなた（Codex）は、この指示書に沿ってコードを書きます。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

先生が、授業に URL（動画・サイト）を付けられるようにする。生徒は、授業の画面からその動画を再生したり、サイトを開いたりできる。

- 要件定義書 `docs/requirements.md` の「授業の共通資料（先生が登録し、配布先のクラスの生徒と先生が見る）」を広げるもの（2026-11-20 にユーザーが依頼）。
- 写真・PDF（`materials`）とは別の項目にする。Drive・GAS は使わない（学校の回線でも Firebase は届くため）。

## データ

`lessons/<classId>/<lessonId>/links/<linkId>` = `{ url: 文字列, title: 文字列, order: 数 }`

- `linkId` は `newId()`（`js/ids.js`）。
- 規則（`docs/setup/rules.json`）は**変えない**（授業は先生だけが書ける。今の規則のままで書ける・読める）。
- `materials` の中には入れない（`materialList`・`fileRefs`・手書きの規則が `materials` を見ているため）。

## 作る・変えるファイル

### 1. `js/config.js`

`materialsPerLesson` の近くに足す:

```js
  // 授業に付けるリンク（動画・サイト）の数と文字数
  linksPerLesson: 8,
  linkTitleMax: 60,
  linkUrlMax: 500,
```

### 2. `js/link-logic.js`（新しく作る。計算だけ。通信・DOM なし）

- `cleanLinkUrl(value)` → 文字列 または `null`
  - 文字列でない → `null`。前後の空白を取る。空 → `null`。
  - `https://` で始まらない（大文字小文字は区別しない）→ `null`。
  - `new URL()` で読めない、`protocol !== 'https:'`、`hostname` が空、`username`・`password` がある → `null`。
  - よければ `url.href` を返す。
- `checkLink({ url, title }, { urlMax, titleMax })` → `null` またはエラーの印
  - `url` が文字列でない・空白だけ → `'no-url'`
  - `url`（空白を取ったあと）の長さが `urlMax` をこえる → `'long-url'`
  - `cleanLinkUrl(url)` が `null` → `'bad-url'`
  - `title` が文字列でない → `'bad-title'`
  - `title`（空白を取ったあと）の長さが `titleMax` をこえる → `'long-title'`
  - `title` は空でもよい。
- `youtubeId(url)` → 11 文字の id または `null`
  - `cleanLinkUrl` を通らないもの → `null`。
  - ホストが `www.youtube.com`・`youtube.com`・`m.youtube.com`: パスが `/watch` なら `v` の値、`/shorts/<id>`・`/embed/<id>`・`/live/<id>` なら `<id>`。
  - ホストが `youtu.be`: パスの最初の部分。
  - ホストが `www.youtube-nocookie.com`: `/embed/<id>`。
  - id が `^[A-Za-z0-9_-]{11}$` に合わなければ `null`。それ以外のホスト（`evil-youtube.com`・`youtube.com.example.org` など）は `null`。
- `youtubeStart(url)` → 始める秒（0 以上の整数）
  - クエリの `t`（なければ `start`）を読む。`90`・`90s`・`1m30s`・`1h2m3s` の形 → 秒。読めない・負・86400 より大きい → `0`。
- `embedUrl(url)` → 文字列 または `null`
  - `youtubeId(url)` が `null` → `null`。
  - `https://www.youtube-nocookie.com/embed/<id>?rel=0&playsinline=1`、始める秒が 1 以上なら `&start=<秒>` を付ける。
- `linkHost(url)` → 表示用のホスト名（`www.` を外す）。読めなければ `''`。
- `linkLabel(link)` → `title`（空白を取って空でなければ）、空なら `linkHost(link.url)`。
- `linkList(links)` → 配列。`links` がオブジェクトでなければ `[]`。
  - 値がオブジェクトの項目だけを対象にし、1 件ごとに `{ id, url, title, order, ok, video }` を返す。
    - `ok`: `cleanLinkUrl(url) !== null` かつ `title` が文字列 かつ `order` が 0 以上の有限の数。
    - `ok` のとき `url` は `cleanLinkUrl` の戻り値。`ok` でないとき `url` は `''`（**開けないアドレスを、そのまま外に出さない**）、`title` は文字列ならその値・ちがえば `''`、`order` は数でなければ `Number.MAX_SAFE_INTEGER`。
    - `video`: `ok` かつ `embedUrl(url) !== null`。
  - `order` の小さい順、同じなら `id` の順に並べる。
- `nextLinkOrder(links)` → 今ある `order`（0 以上の有限の数）の最大 + 1。無ければ 0。

### 3. `js/repo.js`

- `toLesson` に `links: isObj(l.links) ? l.links : {}` を足す。
- `updateLesson` の上のコメントに「リンク」も残ることを足す（動きは変えない）。
- 足す関数（`addLessonTerm` と同じ書き方。`net.update('', …)` で 1 回）:
  - `addLessonLink(classId, lessonId, linkId, { url, title, order }, now)` → `links/<linkId>` に `{ url, title, order }` と `updatedAt`。
  - `removeLessonLink(classId, lessonId, linkId, now)` → `links/<linkId>` を `null` と `updatedAt`。
  - `setLinkOrders(classId, lessonId, orders, now)` → `setMaterialOrders` と同じ形で `links/<id>/order`。空なら何もしない。

### 4. `js/views/parts/video-player.js`（新しく作る）

`openVideo({ title, src, pageUrl })` → `{ close() }`

- `<dialog class="video-dialog">` を `document.body` に足して `showModal()` する（`js/ui.js` の `confirmDialog` と同じやり方。`closeAllDialogs()` で閉じられること）。
- 中身: 見出し（`title`）、`iframe`、下に「うまく再生できないときは、別のタブで開く」のリンク（`href=pageUrl`・`target="_blank"`・`rel="noopener noreferrer"`）、「とじる」ボタン。
- `iframe` の属性: `src`、`title`（`title` と同じ）、`allow="fullscreen; encrypted-media; picture-in-picture"`、`allowfullscreen`、`referrerpolicy="strict-origin-when-cross-origin"`、`sandbox="allow-scripts allow-same-origin allow-presentation"`、`loading="lazy"` は付けない。
- 閉じる（ボタン・Esc・`close()`）ときは、**`iframe` を DOM から外してから**ダイアログを消す（音が鳴り続けないように）。2 回閉じても壊れない。
- `src` が `https://www.youtube-nocookie.com/embed/` で始まらないときは、開かずに `null` を返す。

### 5. `js/views/parts/link-pane.js`（新しく作る）

`linkPane({ lesson })` → `{ node, destroy() }`

- `linkList(lesson.links)` のうち **`ok` のものだけ**を出す。1 件も無ければ `node` は `hidden` の空の `div`（見出しも出さない）。
- あるとき: `el('div', { class: 'link-pane' }, el('h3', { text: '動画・サイト' }), ul)`。
- 1 件の形（`li.link-row`）:
  - 動画（`video`）: `button.btn.link-open`。文字は「▶ <linkLabel>」、下に小さく「動画（この画面で再生）」。押すと `openVideo({ title: linkLabel, src: embedUrl(url), pageUrl: url })`。
  - サイト: `a.btn.link-open`（`href=url`・`target="_blank"`・`rel="noopener noreferrer"`）。文字は「↗ <linkLabel>」、下に小さく「サイト（別のタブで開く）・<linkHost>」。
- `destroy()` は、開いている動画を閉じ、イベントを外す。
- `href` に入れるのは `linkList` が返した `url` だけ（`lesson.links` の生の値を入れない）。

### 6. `js/views/student-lesson.js`・`js/views/teacher-record.js`

- 「先生の資料」の節の `materialsArea` のすぐ下に、`linkPane({ lesson })` の `node` を入れる（授業を読みこんだあと、`materialPane` を作る所で作る）。画面を離れるとき・読み直すときに `destroy()` を呼ぶ。

### 7. `js/views/teacher-lesson.js`

「授業の資料」の節の下に、節を足す:

- `section.card.lesson-links`、見出し「動画・サイトのリンク」、説明「YouTube の動画は、生徒の画面の中で再生されます。そのほかのサイトは、別のタブで開きます。」
- フォーム（`novalidate`）: 「アドレス」（`type="url"`・`inputmode="url"`・`placeholder="https://…"`・`autocomplete="off"`）、「名前（空でもよい）」（`maxlength=CONFIG.linkTitleMax`）、「＋ 足す」。
- 足すとき:
  - `!ready`・保存中・ほかの処理中は何もしない（今の `materialBusy`・`saving` と同じ考え。リンク用に `linkBusy` を作り、`syncControls` でボタンを止める）。
  - `checkLink` の結果でエラーを出す（`role="alert"` の `p.error`。フォームのすぐ下）:
    - `no-url`: 「アドレスを入れてください。」
    - `long-url`: 「アドレスが長すぎます（500 文字まで）。」
    - `bad-url`: 「https:// で始まるアドレスを入れてください。」
    - `bad-title`・`long-title`: 「名前は 60 文字までです。」
  - 今のリンクの数（`Object.keys(lesson.links).length`。形のおかしいものも数える）が `CONFIG.linksPerLesson` 以上 → 「リンクは 8 個までです。」
  - 同じアドレス（`cleanLinkUrl` の結果が同じ）がすでにある → 「同じアドレスが、もう入っています。」
  - よければ `ctx.repo.addLessonLink(classId, lessonId, newId(), { url: cleanLinkUrl(url), title: title.trim(), order: nextLinkOrder(lesson.links) }, ctx.now())`。成功したら `lesson.links` に足し、一覧を描き直し、入力を空にし、`toast('リンクを足しました。')`。失敗したら、エラーの所に「足せませんでした。もう一度ためしてください。」（入力は残す）。
- 一覧（`linkList(lesson.links)` の全部。`ok` でないものも出す）:
  - `ok`: 種類（「動画（生徒の画面で再生）」／「サイト（別のタブで開く）」）、`linkLabel`、アドレス（小さく。長いときは CSS で折り返す）。ボタン「ためす」（動画は `openVideo`、サイトは別のタブ。`a` で作ってよい）・「上へ」・「下へ」・「消す」。
  - `ok` でない: 「開けないリンクです（生徒には出ません）」と目立つ印（`statusChip` などの今ある部品）を出し、ボタンは「消す」だけ。
  - 1 件も無い: 「まだリンクがありません。」
- 「上へ」「下へ」: `moveInOrder(linkList(lesson.links), id, dir)` → `ctx.repo.setLinkOrders`。`moveMaterial` と同じ流れ・同じ文（「順番を変えました。」／失敗の文）。
- 「消す」: `confirmDialog`（題「リンクを消しますか？」・本文「この授業から外します。」・`okLabel: '消す'`・`danger: true`）→ `ctx.repo.removeLessonLink` → 一覧を描き直し `toast('リンクを消しました。')`。失敗は「消せませんでした。もう一度ためしてください。」
- 画面を離れる確認（`okToLeave`）: `linkBusy` のときは `saving`・`materialBusy` と同じ扱い（「処理しています。…」）。入力の途中の文字は、確認の対象にしない。
- 授業を読み直す所（ほかのクラスへ資料を付けたあとの `lesson.materials = found.materials` など）で、`lesson.links` を消してしまわないこと。

## 端の場合

- 不正な入力:
  - `http://`・`javascript:`・`data:`・`ftp://`・`//example.com`・空白だけ・数字・`null`・オブジェクト → 足せない（`bad-url` か `no-url`）。保存されているデータがこの形でも、生徒の画面には出さず、`href`・`src` に入れない。
  - 利用者名・パスワードの付いたアドレス（`https://a:b@example.com`）→ `bad-url`。
  - 500 文字をこえるアドレス・60 文字をこえる名前 → 足せない。
  - YouTube に見えるが id が 11 文字でない・ホストがちがう → 動画ではなく、ふつうのサイトとして扱う（別のタブで開く）。
  - `links` がオブジェクトでない・中の値が文字列や数 → 無いものとして扱う。
- 重複と境界:
  - 同じアドレス（`cleanLinkUrl` の結果が同じ）は 2 回足せない。名前が同じでアドレスがちがうものは足せる。
  - 8 個までは足せる。9 個目は足せない。ちょうど 500 文字のアドレス・ちょうど 60 文字の名前は足せる。
  - `order` が同じものは `id` の順。1 個だけのとき、「上へ」「下へ」は何もしない。
- 違反や失敗の見せ方:
  - 入力のまちがいは、フォームのすぐ下に赤い文で出し、保存しない。
  - 形のおかしい保存データは、先生の画面で「開けないリンクです（生徒には出ません）」の印を付けて出し、消せるようにする。生徒の画面には出さない。
  - 通信の失敗は、上に書いた文を出し、画面の一覧は変えない。
  - 動画が再生できない（持ち主が埋めこみを禁じている・回線で止められている）ときは、アプリからは見分けられないので、動画の枠の下の「うまく再生できないときは、別のタブで開く」で開けるようにしておく。
