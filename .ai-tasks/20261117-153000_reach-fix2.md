## 直すこと（`js/reach-targets.js`）

- 「中つぎの候補: Deno Deploy（deno.dev）」を、一覧から外す。
- Firebase のホスティングを一覧に入れる。設定にプロジェクト ID が無いので、**データベースの URL のホスト名から取り出す**: ホスト名の先頭のラベルが `<ID>-default-rtdb` の形のとき、`<ID>` をプロジェクト ID とし、`https://<ID>.web.app/` を「Firebase のホスティング（web.app）」として、「Google のファイル置き場」の次に入れる。その形でないとき・取れないときは、今のとおり外す。

## 端の場合

- 不正な入力: データベースの URL が無い・`https://` でない・ホスト名の先頭が `-default-rtdb` で終わらない・ID が空・ID に英小文字と数字と `-` 以外が入る → ホスティングを外す。
- 重複と境界: ほかの行き先の順番は変えない。
- 違反や失敗の見せ方: 外した行き先は、表に出さない。
