# 実装指示書: 先生がクラスごとに、理科クエストの「今の単元」を決める（段階 3・授業ログ側）

あなた（Codex）は、この指示書に沿ってコードを書きます。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。先に `docs/superpowers/specs/2026-11-19-rika-link-design.md`（2 章・4 章・5 章の段階 3・6 章）と、規則の前の指示書 `.ai-tasks/20261119-160000_rika-rules.md` を読んでから始めてください。

## 目的

設計書の段階 3「単元を決める」の授業ログ側。先生がクラスごとに、理科クエスト（別のアプリ）の「今の単元」を決める。決めた単元は、生徒の最初の画面の「理科クエスト」のカードに出す。理科クエスト側（となりの `理科アプリ` フォルダ）は別の指示書で作るので、このフォルダの外は読まない・変えない。

## データの形

| 場所 | 中身 | 読める人 | 書ける人 |
|---|---|---|---|
| `rika/classUnit/<classId>` | 単元の id の文字列（例 `light`）。決めていないときは、この場所が無い | 先生・そのクラスの生徒 | 先生 |

## 変えるファイルと内容

### 1. `docs/setup/rules.json`

`rika` の下に `classUnit` を足す（`state`・`log` は変えない）。

```json
"classUnit": {
  ".read": "auth != null && root.child('teacherList').child(auth.uid).val() === true",
  "$classId": {
    ".read": "auth != null && (root.child('teacherList').child(auth.uid).val() === true || root.child('memberOf').child(root.child('accounts').child(auth.uid).val()).child($classId).val() === true)",
    ".write": "auth != null && root.child('teacherList').child(auth.uid).val() === true && (!newData.exists() || root.child('classes').child($classId).exists())",
    ".validate": "newData.isString() && newData.val().matches(/^[a-z0-9-]{1,40}$/)"
  }
}
```

### 2. `js/rika-units.js`（新しく作る。純粋なモジュール）

  | 学年 | id | 名前 |
  |---|---|---|

  | 1 | light | 光の世界 |
  | 1 | sound | 音の世界 |
  | 1 | force | 力のはたらき |
  | 1 | substance | 身のまわりの物質 |
  | 1 | solution | 水溶液 |
  | 1 | state-change | 状態変化 |
  | 1 | plants | 植物のなかま |
  | 1 | animals | 動物のなかま |
  | 1 | volcano | 火山と地震 |
  | 1 | strata | 地層と大地の変化 |
  | 2 | chemical-change | 化学変化と原子・分子 |
  | 2 | body | 生物のからだのつくりとはたらき |
  | 2 | electricity | 電流とその利用 |
  | 2 | weather | 天気とその変化 |
  | 3 | motion | 運動とエネルギー |

  | 3 | heredity | 生命の連続性 |
  | 3 | space | 地球と宇宙 |
  | 3 | nature | 自然と人間 |

- 出すもの:
  - `RIKA_UNITS`: `[{ id, title, grade }]`（上の順。凍らせる）
  - `rikaUnit(id)` → その行、無ければ `null`（文字列でないものも `null`）
  - `rikaUnitLabel(id)` → `'1年 光の世界'` の形。表に無い id は `null`
  - `cleanClassUnit(value)` → データベースから読んだ値を確かめる。`/^[a-z0-9-]{1,40}$/` に合う文字列ならそのまま、それ以外（数・空・オブジェクト・長すぎ）は `null`

### 3. `js/repo.js`

- `async getClassUnit(classId)` → `rika/classUnit/<classId>` を読み、`cleanClassUnit` を通して返す（文字列か `null`）。
- `async listClassUnits()` → `rika/classUnit` を丸ごと読み、`{ <classId>: <単元の id> }` を返す（形のおかしい値の行は入れない。無ければ `{}`）。先生だけが呼ぶ。
- `async setClassUnit(classId, unitId)` → `unitId` が `null` なら、その場所を消す。文字列なら `cleanClassUnit` に通し、`null` になるもの（形がおかしい）は `TypeError` を投げて書かない。
- クラスを消す処理が `repo.js` にあるなら、そこで `rika/classUnit/<classId>` も一緒に消す（無ければ何もしない。報告に書く）。

### 4. `js/views/teacher-classes.js`（先生の「クラス」の一覧）

- クラスの一覧を読むときに、`listClassUnits()` も読む。これが失敗しても、クラスの一覧は今までどおり出す。そのときは、一覧の上に「理科クエストの単元を読みこめませんでした。」（`error`・`role="alert"`）と「もう一度」のボタンを出し、各行の単元の表示とボタンは出さない。
- 各クラスの行に、次を足す。
  - 文: 「理科クエストの単元: 1年 光の世界」。決めていないときは「理科クエストの単元: 決めていません（生徒が選びます）」。
  - 保存してある id が `RIKA_UNITS` に無いとき: 「理科クエストの単元: 教材にない単元です（<id>）。生徒の側では、決めていないのと同じになります。」とし、`statusChip('warn', '要確認')` を付ける。
  - ボタン「単元を決める」（`aria-label` は「<クラスの名前> の理科クエストの単元を決める」）。
- 「単元を決める」を押すと、今ある `openForm` で窓を出す。`openForm` が選ぶ欄（`select`）に対応していなければ、対応を足す（今ある使い方は変えない）。
  - 題: 「理科クエストの単元を決める」。説明: 「決めると、このクラスの生徒が次に理科クエストを開いたときに、この単元になります。生徒は、ほかの単元も進められます。」
  - 選ぶ欄: いちばん上が「決めない（生徒が選ぶ）」。その下に、学年ごと（`optgroup` 「1年」「2年」「3年」）に 20 個の単元。今の値を選んだ状態で開く。教材にない id が入っているときは「決めない」を選んだ状態で開く。
  - 「決める」で `setClassUnit` を呼ぶ。失敗したら窓の中に「つながりません。もう一度ためしてください。」を出し、窓は閉じない。成功したら窓を閉じ、`toast('理科クエストの単元を決めました。')`（「決めない」にしたときは `toast('理科クエストの単元を、決めない に戻しました。')`）、その行の表示を新しくする。
  - 今の値と同じものを選んで「決める」を押したときは、書きこまずに窓を閉じる。
- 見た目は、今あるクラスの行の書き方（`css/app.css` の `.class-row` など）に合わせ、必要な分だけ `css/app.css` に足す。ボタンは 44×44px 以上。幅 375px でも横にはみ出さない。

## 端の場合

- 不正な入力: データベースの値が数・空の文字列・オブジェクト・41 文字以上・大文字や記号入り → `cleanClassUnit` が `null` にし、「決めていない」と同じに扱う。形は合うが教材に無い id → 先生の画面に「教材にない単元です」の印、生徒のカードには出さない。`setClassUnit` に形のおかしい値 → 書かずに `TypeError`。
- 重複と境界: 今と同じ値を選ぶ → 書きこまない。「決めない」→ 場所を消す。クラスが 0 個 → 今までどおり。生徒がクラスに入っていない → カードに単元の行を出さない。生徒が年度を切りかえる → そのクラスの単元だけ出る。ちょうど 40 文字の id は通り、41 文字は通らない。
- 違反や失敗の見せ方: 先生の保存の失敗 → 窓の中に赤い文、窓は閉じない。先生の読みこみの失敗 → 一覧の上に赤い文と「もう一度」。生徒が規則で読めない・通信の失敗 → 単元の行を出さないだけで、ほかの表示は今までどおり。
