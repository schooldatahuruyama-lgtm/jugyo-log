# 実装指示書: 先生のグラフを画面いっぱいの幅にする・見出しの番号を絵に変える

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

1. Claude Code がブラウザで確かめて見つけた点: 先生の記録の画面で、1 本の帯のグラフが左のせまい列（約 230px）に入っていて、帯が短い。区切りの幅を 56px 以上にする決まりのために、8% と 17% が同じ長さになり、割合が長さに出ない。先生が承認した見本（`.superpowers/brainstorm/6260-1794483811/content/teacher-ui-ideas.html`）では、帯は画面いっぱいの幅だった。**帯を、一覧の上に、画面いっぱいの幅で出す。**
2. 先生（ユーザー）が、見本（`.superpowers/brainstorm/6260-1794483811/content/icon-ideas.html` の「案 J-1」）を見て決めた（2026-11-15）: **生徒の授業ページの見出しの番号（①②③）をやめて、中身を表す小さな絵にする。**

（要件定義書 `docs/requirements.md` の「UI/UX 方針」。置くもの・順番・動きは変えない。）

## 変えるファイル

`js/views/teacher-review.js`、`js/views/student-lesson.js`、`js/views/teacher-record.js`、`css/app.css`。新しく作ってよいファイル: `js/views/parts/heading-icon.js`（絵を作る小さな部品）。ほかのファイルは変えない。

### 1. 先生の記録の画面（`js/views/teacher-review.js`・`css/app.css`）

- 今の「左に理解度の枠・右に生徒の記録」の 2 列をやめ、**上に「理解度」の枠（画面の幅いっぱい）、その下に「生徒の記録」**の 1 列にする（横向き・縦向きとも）。
- 帯は、枠の幅いっぱい。区切りの幅は人数の割合で、どの区切りも 56px 以上（今のまま）。横向き（1180px）では、3% の区切りでも、割合に近い長さの差が見えるようになる。
- 帯の下の色の説明（押せない）は、横 1 列に並べる（入りきらなければ折り返す）。
- 幅がとてもせまくて、56px × 区切りの数が入りきらないときだけ、今の横スクロールを残してよい。
- ほかの動き（押してしぼりこむ・コピー・並び順・行の色の線）は変えない。

### 2. 見出しの絵（J-1）

- `js/views/parts/heading-icon.js`: `headingIcon(kind) → SVGElement を入れた <span>`。`kind` は `'teacher'`（黒板）・`'mine'`（鉛筆）・`'reflect'`（吹き出し）。知らない `kind` は例外にせず、空の `<span>` を返す。
  - `<span>` は、38×38px・角の丸み 10px・その枠の色（`--teacher`・`--mine`・`--reflect`）で塗る。中の SVG は 24×24px・線だけ（`fill: none`・白い線・太さ 2・線の端と角は丸）。`aria-hidden="true"`（見出しの文字が中身を伝えるので、絵は飾り）。
  - SVG は `document.createElementNS('http://www.w3.org/2000/svg', …)` で作る（`innerHTML` を使わない）。`viewBox="0 0 24 24"`。形（パスの `d`）:
    - 黒板: `<rect x="3" y="4" width="18" height="12" rx="1.5">` と `M8 20h8M12 16v4M7 9h6M7 12h3`
    - 鉛筆: `M4 20l1-4L16 5l3 3L8 19l-4 1z` と `M14 7l3 3`
    - 吹き出し: `M4 5h16v11H10l-4 4v-4H4z` と `M8 9h8M8 12h5`
- `js/views/student-lesson.js`: 3 つの枠の見出しの、番号の丸をやめて、`headingIcon` の絵にする（① → 黒板、② → 鉛筆、③ → 吹き出し）。見出しの文字と、その下の説明は今のまま。
- `js/views/teacher-record.js`: 3 つの枠の見出しにも、同じ絵を付ける（先生の資料 → 黒板、この生徒の記録 → 鉛筆、振り返り → 吹き出し）。
- `css/app.css`: 番号の丸のための決まりは、使わなくなるので消してよい。絵の四角の決まりを足す。

## 端の場合

- 不正な入力: `headingIcon` に知らない値・`null` → 空の `<span>`（落ちない）。
- 重複と境界: 生徒が 0 人のとき、帯は出さず、文を出す（今のまま）。区切りが 1 つだけ（100%）のとき、帯いっぱいの 1 つの区切り。縦向き（820px）でも、帯と色の説明が横にはみ出さない（はみ出すときは、帯の中だけがスクロールする）。
- 違反や失敗の見せ方: 変えない（しぼりこみ中の 1 行・帯の区切りの枠・読みこみの失敗の文は、今のまま）。絵が出なくても、見出しの文字で中身が分かる。
