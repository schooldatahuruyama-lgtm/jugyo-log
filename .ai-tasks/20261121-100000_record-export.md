# 実装指示書: 記録の書き出し（段階 3）

あなた（Codex）は、この指示書に沿ってコードを書きます。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

設計書 `docs/superpowers/specs/2026-11-12-jugyo-log-design.md` の 3 章・3.1「生徒の Drive に記録を残す（段階 3）」。先生が異動して先生の Drive が使えなくなっても、生徒が自分の記録を手元に残せるようにする。

生徒が、年度（クラス）・単元・授業を選ぶと、その授業の中身を順に並べた 1 つの「読み物」の画面ができる。生徒はそれを iPad の印刷の画面から PDF にして、自分の Drive に保存する。アプリは生徒の Google アカウントに入らない。規則（`docs/setup/rules.json`）・GAS・`js/rules-probe.js`・`check.html` は変えない（生徒が今も読めるものだけを読む）。

## 画面の動き（先生に伝えてある。変えない）

1. 生徒の最初の画面（`js/views/student-home.js`）の、年度と並べ方の所（`filters`）に、ボタン「記録をまとめて保存」を足す。押すと、今の年度（`current.id`）で新しい画面へ行く。クラスに入っていないときは出さない。
2. 新しい画面（`#/export/<classId>`）の「えらぶ」の部分:
   - 「‹ 一覧へ」（`home` へ。`classId` を付ける）。
   - 年度の選び（`myClasses` の一覧。変えると、その `classId` の同じ画面へ移る）。
   - 単元の選び: その年度の単元のうち、授業が 1 つ以上あるもの（`sortUnits` の順）。最後に「単元に入っていない授業」（`unitId` が空、または単元の一覧に無い授業が 1 つ以上あるときだけ）。最初は、いちばん新しい日付の授業が入っている選びを選んでおく。
   - 授業の一覧（チェックボックス。日付の古い順。日付と授業名）。最初は全部に印。「全部えらぶ」「全部はずす」のボタン。
   - 「先生の資料も入れる」のチェックボックス（最初は印あり）。
   - 「えらんだ授業: ○ 個」。
   - ボタン「読み物を作る」。印が 0 個、または `CONFIG.export.maxLessons`（15）をこえたときは押せない。こえたときは「一度に作れるのは 15 個までです。授業をへらしてください。」を `role="alert"` で出す。
   - まだ送れていない記録があるとき（`pendingLessonCount(ctx.drafts, studentId, ctx.inkDrafts) > 0`）は、「まだ保存できていない記録が ○ 件あります。その分は、読み物に入りません。一覧にもどって、送れてから作ってください。」を `notice` で出す（作るのは止めない）。
3. 「読み物を作る」を押すと、授業を 1 つずつ順に読みこむ（同時に読まない）。その間、「○ / ○ 個めの授業を読みこんでいます…」（`role="status"`）と「やめる」を出し、えらぶ部分は押せなくする。「やめる」で、えらぶ部分にもどる（途中まで作った絵は片付ける）。
4. できたら、読み物を出す。その上（印刷には出さない）に:
   - 「PDF にして保存する」（`window.print()`）。
   - 番号つきの手順（文だけ）: ①「PDF にして保存する」を押す ② 印刷の画面で、紙の絵を 2 本の指で広げる ③ 右上の共有のボタンを押す ④「ファイルに保存」か「ドライブ」をえらび、自分の Google ドライブに保存する。その下に「パソコンでは、印刷の画面で『PDF に保存』をえらびます。」
   - 「えらび直す」（えらぶ部分にもどる。絵は片付ける）。
   - 読みこめなかったものがあるとき: 「読みこめなかったものが ○ 件あります。その場所に印を出しています。」（`role="alert"`）と「もう一度読みこむ」（同じえらびで、最初から作り直す）。
   - 絵の数が上限で入らなかったものがあるとき: 「絵が多いので、○ 枚は入っていません。授業をへらして、分けて作ってください。」（`role="alert"`）。
5. 読み物の中身:
   - 表紙の部分: 「授業ログの記録」、年度とクラス（`classLabel`）、出席番号（あれば）、生徒 ID、単元の名前（または「単元に入っていない授業」）、授業の数、作った日（`ctx.now()` から `YYYY/MM/DD`）。名前の欄は作らない。
   - 授業ごとに（日付の古い順。印刷では授業ごとに新しいページから）:
     - 日付（`dateLabel`）と授業名（空なら「（授業名なし）」）。
     - 重要用語（`mergedTerms(lesson, myTerms)` の文字。無ければこの項目を出さない）。
     - 先生の資料（「先生の資料も入れる」に印があるとき。`materialList` の順）: 名前と種類（板書／配布資料）。写真は絵 1 枚。PDF はページごとの絵。自分の書きこみがあれば、絵に重ねる。リンク（`linkList`）は、名前（`linkLabel`）とアドレスを文字で出す（押せなくてよい）。資料もリンクも無ければ「（資料はありません）」。
     - メモ: 文字（空で手書きも無ければ「（書いていません）」）と、手書きの絵。
     - 自分の写真・PDF（`attachmentList` の順。`attachmentLabels` の名前）。書きこみを重ねる。無ければこの項目を出さない。
     - 振り返り: 理解度（`levelLabel`）、分かったこと・学んだこと、疑問・まだ分からないこと（文字と手書きの絵。メモと同じ決まり）。
     - 先生の返事（`getReply`）: 文があればその文。`seen` が真なら「✓ 先生が見ました」。どちらも無ければこの項目を出さない。
     - 記録が 1 つも無い授業（`getRecord` が `null`）は、「この授業は、まだ何も書いていません。」を出し、先生の資料はふつうに出す。
   - 読みこめなかった所には、その場所に枠つきの印を出す: 「！ この写真は読みこめませんでした」「！ この PDF は読みこめませんでした」「！ この手書きは読みこめませんでした」「！ この書きこみは読みこめませんでした（絵だけ出しています）」「！ この授業の記録は読みこめませんでした」「！ 先生の返事は読みこめませんでした」。印刷にも出す。
   - PDF は、最初の `CONFIG.export.pdfPages`（20）ページと、それより後ろで自分の書きこみがあるページを出す。出さなかったページがあれば、その PDF の最後に「残り ○ ページは入っていません。」を出す。

## 変えるファイル・作るファイル

### 1. `js/config.js`

```js
// 記録の書き出し: 一度に作れる授業の数、絵の数、PDF 1 つのページ数、絵の長辺と画質
export: { maxLessons: 15, maxPictures: 150, pdfPages: 20, imageEdge: 1200, jpegQuality: 0.8 },
```

### 2. `js/router.js`

- `export: [null, 'student-export', 'student']` を足す。
- `parseRoute`: `#/export/<classId>`（`CLASS_ID` に合うもの。部品はちょうど 3 つ）→ `{ name: 'export', params: { classId } }`。合わなければ今までどおり `not-found`。
- `routeHash('export', { classId })` → `#/export/<classId>`。

### 3. `js/export-logic.js`（新しい。純粋な関数だけ。画面・通信を使わない）

- `exportScopes(lessons, units)` → `[{ id, label, lessons }]`。`id` は単元の id、または `''`（単元に入っていない授業）。`lessons` は日付の古い順（同じ日付は `createdAt`、その次に `id` の順）。授業が 0 個の単元は入れない。`units` が配列でないときは、全部を `''` の選びに入れる。
- `defaultScope(scopes)` → いちばん新しい日付の授業が入っている選びの `id`（同じなら、先に並んでいる方）。選びが無ければ `null`。
- `checkSelection(ids, scope, { maxLessons })` → `{ ok, count, reason }`。`reason` は `null`・`'none'`・`'many'`。`ids` のうち、その選びに無い id・重なった id は数えない。`ids` が配列でないときは 0 個。
- `pdfPagesToShow(pageCount, inkPages, limit)` → `{ pages: number[], skipped: number }`。`pages` は 1〜`min(pageCount, limit)` と、`limit` より後ろで `inkPages` にあるページ（1〜`pageCount` の整数だけ。重なりなし・小さい順）。`pageCount` が正の整数でないときは `{ pages: [], skipped: 0 }`。
- `pageInkPlaces(record, place, fileId)` → `[{ page, index }]`。`record.ink` のうち、`splitInkPlace(name)?.place === place` で `index.on === fileId` のもの。ページの小さい順。
- `inkCrop(ink)` → `{ top, height }` または `null`（線が無い）。`inkBounds` を使い、上下に 12 の余白を付けて、0〜`ink.h` に収める。高さは 1 以上。
- `exportDateLabel(ms)` → `YYYY/MM/DD`。数でない・無限・日付にならないときは `''`。
- `countProblems(lessons)` → 読み物の入れ物（下の 4）の中の、読みこめなかった印の数。

### 4. `js/export-flow.js`（新しい。1 つの授業の全部の中身を、ここ 1 か所で集める。設計書 3.1 の決まり）

```js
export async function gatherLesson({ repo, files, classId, lesson, studentId, myTerms, withMaterials, draw, budget, signal })
```

- 返すもの（ふつうの値だけの入れ物。画面の部品は入れない）:

```js
{
  id, date, title,
  terms: ['…'],
  materials: [{ id, kind, type, name, pictures: [絵], skipped: 0, problem: null | 'image' | 'pdf' }],   // withMaterials が偽なら null
  links: [{ label, url }],                                                                       // withMaterials が偽なら null
  record: { memo, learned, question, level } | null,
  recordProblem: false,          // getRecord が失敗したら true（record は null）
  inks: { memo: 絵 | null, learned: 絵 | null, question: 絵 | null },
  attachments: [{ slot, label, type, pictures: [絵], skipped: 0, problem: null | 'image' | 'pdf' }],
  reply: { text, seen } | null,
  replyProblem: false,
}
```

- 「絵」は `{ url, width, height, page: number | null, problem: null | 'ink' | 'budget' }`、または読みこめなかった手書きの `{ url: null, problem: 'ink' }`。`problem: 'ink'` で `url` があるものは「書きこみだけ読めなかった絵」。`problem: 'budget'` は「絵の数の上限で入れなかった」（`url: null`）。
- 読む順: `repo.getRecord` と `repo.getReply`（この 2 つは同時でよい）→ 先生の写真（`files.loadImages` で、その授業の分をまとめて）→ 先生の PDF（`files.loadFile`。1 つずつ）→ 自分の写真・PDF（`files.loadStudentFile`。1 つずつ）→ 手書き（`loadInkFlow`。1 つずつ）。GAS を同時に 2 つ以上呼ばない。
- 書きこみの目録: 写真は `pictureIndex(record, place, fileId)`（`place` は資料の id、または添付の `slot`）。PDF のページは `pageInkPlaces`。`on` がファイルとちがう古い書きこみは使わない（今の画面と同じ）。
- 絵を作る所は、引数の `draw` に任せる（テストでは にせ物を渡す）:
  - `draw.picture(blob, ink)` → `{ url, width, height }`（写真に書きこみを重ねて JPEG にする。`ink` は `null` でもよい）
  - `draw.ink(ink)` → `{ url, width, height }` または `null`（線が無い）
  - `draw.openPdf(blob)` → `{ pageCount, page(number, ink) → { url, width, height }, close() }`
- 失敗は投げずに、その場所の `problem` に入れる（1 つの失敗で、ほかを止めない）。`getRecord` の失敗は `recordProblem: true`、`getReply` の失敗は `replyProblem: true`。ただし `signal.aborted` になったら、すぐ `AbortError`（`name === 'AbortError'`）を投げる。開いた PDF は、成功でも失敗でも中止でも必ず `close()` する。
- `budget` は `{ left: number }`。絵を 1 枚作るたびに 1 へらす。0 のときは作らずに `problem: 'budget'` の絵を入れる（ファイルの読みこみもしない）。手書きの絵（`inks`）も数える。
- `exportLessons({ …, lessons, onProgress })` → 上を授業の順に 1 つずつ呼び、`onProgress(done, total)` を呼ぶ。返すのは入れ物の配列。途中で中止されたら `AbortError`。

### 5. `js/export-draw.js`（新しい。ブラウザの物を使う所だけ）

- `createExportDraw({ document, URL, createImageBitmap?, openPdf, config })` → 上の `draw` と、`dispose()`（作った `blob:` のアドレスを全部 `URL.revokeObjectURL` し、開いたままの PDF を閉じる）。
- 写真: 長辺を `config.export.imageEdge` までに縮めてキャンバスに描き、書きこみ（`CONFIG.ink.width` を横幅とする座標。色は `CONFIG.ink.colors[c]`、太さは `CONFIG.ink.widths[w]` を同じ比で）を重ね、`canvas.toBlob('image/jpeg', jpegQuality)` → `URL.createObjectURL`。作り終わったキャンバスは幅と高さを 0 にして手放す。
- 手書き: 白い地に、`inkCrop` の範囲だけを描く（横は 800 のまま）。
- PDF: `openPdf(await blob.arrayBuffer())`、`renderPage(number, imageEdge)` のキャンバスに書きこみを重ねる。
- 線の描き方は `js/ink-thumb.js` と同じ（`lineCap`・`lineJoin` は `round`）。

### 6. `js/views/student-export.js`（新しい画面）

- 上の「画面の動き」のとおり。書き方は `js/views/student-home.js`・`js/views/teacher-sheet.js` に合わせる（`el`、`alive`、`loadId`、読みこみ中・失敗の文と「もう一度ためす」）。
- 読みこむもの: `repo.myClasses(studentId)`、`repo.listLessons(classId)`、`repo.listUnits(year)`、`repo.getMyTerms(studentId, classId)`。
  - `params.classId` が自分のクラスに無い →「このクラスは見つかりません。」と「一覧へ」。
  - `listLessons` の失敗 →「つながりません。…」と「もう一度ためす」。
  - `listUnits` の失敗 → 全部を「単元に入っていない授業」として出し、「単元を読みこめませんでした。授業は全部ここに出しています。」を `notice` で出す。
  - `getMyTerms` の失敗 → 自分の用語なしで進め、「自分で足した重要用語を読みこめませんでした。その分は、読み物に入りません。」を `notice` で出す。
  - 授業が 0 個 →「まだ授業がありません。」（ボタンは押せない）。
- 画面を離れるとき・作り直すとき・「えらび直す」「やめる」で、`AbortController` で止め、`draw.dispose()` を呼ぶ。止めたあとに届いた結果で、画面を書きかえない。
- 絵は `el('img', { src, width, height, alt, loading: 'eager', decoding: 'async' })`。`alt` は「板書 1（3 ページ）」「メモの手書き」のように、何の絵かが分かる文。
- 文字（メモなど）は `textContent` で入れる（HTML として解釈させない）。改行はそのまま見えるようにする（`white-space: pre-wrap`）。

### 7. `css/app.css`・`css/print.css`

- 画面: 読み物は白い紙のような 1 列（最大幅 800px くらい）。絵は `max-width: 100%; height: auto`。印の枠は、色だけでなく「！」と文で分かるようにする。ボタンは高さ 44px 以上。幅 375px で横にはみ出さない。
- 印刷（`print.css` の `@media print` の中に足す。今ある ID の一覧の決まりはこわさない）: 上の帯・ボタン・えらぶ部分・手順・知らせ（`.no-print`）を消す。授業ごとに `break-before: page`（最初の授業は表紙の続きでよい）。絵は `max-width: 100%; max-height: 240mm; break-inside: avoid`。見出しのすぐ後ろでページが切れないようにする（`break-after: avoid`）。背景は白、文字は黒。
- 今ある `button, .btn { display: none }` の決まりで、読み物の中の物が消えないこと（読み物の中にボタンは置かない）。

### 8. 文書

- `README.md`: 生徒がすることの所に、「記録をまとめて保存」の使い方を 3〜5 文で足す（何が入るか、15 個まで、PDF にして自分の Drive に保存する、アプリに読みこみ直すことはできない）。

## 端の場合

- 不正な入力:
  - アドレスの `classId` に記号がある・自分のクラスでない → 画面を出さず、「見つかりません」を出す。
  - 記録の形がおかしい（文字でない、長すぎる）→ `normalizeRecord(…, { max: CONFIG.recordTextMax })` を通した値を出す。理解度が範囲外 → `levelLabel` の出す文（未入力）。
  - 添付・資料・リンクの形がおかしいもの → `attachmentList`・`materialList`・`linkList` が落とすので、出さない（今の授業の画面と同じ）。
  - 手書きのファイルが壊れている（`loadInkFlow` が投げる）→ 「！ この手書きは読みこめませんでした」。
  - 写真として読めないファイル・開けない PDF → その場所に印。
  - とても大きい PDF（ページが多い）→ 20 ページと書きこみのあるページだけ。残りは文で知らせる。
  - とても多い絵 → `maxPictures`（150）をこえた分は作らず、その場所に「！ 絵が多いので、この絵は入っていません」を出し、上に枚数を出す。
- 重複と境界:
  - 授業 0 個・1 個・15 個（作れる）・16 個（作れない）。印を外して 15 個にすると作れる。
  - 同じ日付の授業が 2 つ → `createdAt`、`id` の順で、毎回同じ順。
  - 単元を消した・変えたあとの授業（`unitId` が一覧に無い）→「単元に入っていない授業」に入る。
  - 書きこみが、入れかえる前のファイルに付いている（`on` がちがう）→ 重ねない。
  - PDF がちょうど 20 ページ → 「残り」の文は出さない。21 ページで書きこみが 21 ページめにある → 21 ページ全部が出て、「残り」は出ない。
  - 「読み物を作る」を 2 回続けて押す → 2 つめは始めない。作っている途中で年度を変える・画面を離れる → 止めて片付ける。
  - 記録が無い授業・返事が無い授業 → 上の「読み物の中身」の決まりどおり。
- 違反や失敗の見せ方: だまって消さない。読みこめなかった所はその場所に印を出し、上に件数と「もう一度読みこむ」を出す。上限で作れないときは、ボタンを押せなくして理由を出す。全部の授業の記録が読めなかったとき（通信が切れている）も、読み物は出して、件数を出す。
