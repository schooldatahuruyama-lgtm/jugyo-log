# 実装指示書: 写真への書きこみ Task 3 — ブラウザで見つけた直し

あなた（Codex）は、この指示書に沿ってコードを直します。進め方は `AGENTS.md` の「実装を頼まれたとき」のとおりです。

## 目的

写真への書きこみ（Task 1・2）を、Claude Code がブラウザ（練習モード、マウス）で確かめて見つけた 3 点を直す。書く・定規・保存・印・開き直し・拡大したときの重なり・写真を消したときの動きは、正しく動いていた。

## 直すこと（`js/views/parts/viewer.js`・`css/app.css`。必要なら `js/views/parts/ink-pad.js`）

### 1. 書いている途中で、写真の位置が動く

今は、はじめの線を書いたあとに「保存中…」の行が出て、写真が下へ 1 行ぶんずれる。次の線が、ねらった場所からずれる。

- 保存の状態・知らせの文を出す場所は、書きこみが使える写真（生徒）では、**はじめから 1 行ぶんの高さを取っておく**（文が無いときも、高さは同じ）。文が出たり消えたりしても、写真の位置と大きさが変わらないこと。
- 文が 1 行に入らないほど長いとき（失敗の文と「もう一度」など）は、高さが増えてよい。

### 2. 「✎ 書きこむ」を押したあと、写真が画面に合う大きさに直らない

今は、道具の並びが出て写真の場所がせまくなっても、写真の大きさが前のまま。100% なのに、スクロールバーが出る。

- 「✎ 書きこむ」を押した・もどしたあと、写真の大きさを、今ある決まり（`sizePicture`）で合わせ直す。拡大率は変えない。
- 道具の並びの折り返しが変わったとき（画面の幅を変えた、など）も、今ある `resize` の合わせ直しで足りることを確かめる。

### 3. 「✎ 書きこむ」が、押してあるのかどうか分からない

今は、押しても見た目が変わらない（`aria-pressed` は変わっている）。

- 押してあるときは、手書きの道具の「動かす／書く」の、選んであるほうと同じ見た目（塗り）にする。

## 端の場合

- 不正な入力: なし（入力を受け取る所は変えない）。
- 重複と境界: 「✎ 書きこむ」を続けて何度押しても、写真の大きさ・位置がくずれない。拡大率 400% でも、線と写真がずれない（今のまま）。読むだけ（先生）と PDF では、1 の高さを取らない（今の見た目のまま）。
- 違反や失敗の見せ方: 変えない（今ある文を、同じ場所に出す）。
