# 1か月分の確認用データと板書

先生の「記録」「まとめ」を確かめるための、架空の中学1年理科のデータです。2026-10-19〜2026-11-16の13授業と、確認用の生徒1〜3番の記録を用意しています。

- `month.json`: 単元・授業・重要用語・板書の文章・生徒の記録。理解度は4が「よく分かった」、1が「全然分からなかった」です。`null` は未記入なので、記録を作らずに残します。
- `boards.js`: `drawDummyBoard(board, { width: 1600, height: 900, quality: 0.85 })` がJPEGのBlobを返します。1600 × 900を基準に拡縮し、端末の書体とタイトルから決まる乱数で描きます。同じ端末・書体・引数なら同じ画像になります。描画自体は通信しません。
- `preview.html`: 手元のサーバーで [板書プレビュー](http://127.0.0.1:8791/tools/dummy/preview.html) を開くと、13枚を日付・授業名・KB表示とともに確認し、JPEGを保存できます。読みこむのは同じフォルダの2ファイルだけです。

アプリへの登録は、Claude Code と先生がブラウザで行います。先生として単元・授業・重要用語・板書画像を追加し、生徒として対応する記録を入力します。この道具がアプリやサーバーにデータを書きこむことはありません。

確認の目安: 1番は13回記入、2番は12回記入（理解度1〜2が5回）、3番は9回記入・未記入4回です。10/21の「入射角」、10/30の「凸レンズ」「焦点」、11/06の「振動数」、11/13の「質量」は、2番と3番の疑問に共通して出てきます。

先生が誤理解に気づけるか確かめるため、10/21の2番（入射角）、10/30の3番（実像の向き）、11/06の2番（大きさと高さ）、11/13の3番（質量）の「分かったこと」に、意図的な誤りを各1つ含めています。板書は正しい説明です。

`tools/pages-branch.ps1` の公開対象に `tools/` は含まれていないため、このフォルダは同スクリプトで作る公開用ブランチには入りません。公開処理やアプリ本体は変更していません。
